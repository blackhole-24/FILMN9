🔧 핵심 기술적 의사결정

  1. pykrx 3,000건 한계 우회
     — 연도별 3년 청크 분할 + _PYKRX_MIN_DATE=20140101 클램핑

  2. 드래그/줌 안정화
     — fixLeftEdge: true + fixRightEdge: true + 일방향 동기화로
       피드백 루프 제거

  3. 시간 포맷 통일
     — dateFmt() 헬퍼가 BusinessDay/UTC타임스탬프/문자열
       3가지 모두 안전 처리

  4. 토스 스타일 정보 패널
     — 팝업 툴팁 제거하고 좌상단 고정 패널로 변경
       → 차트 시야 가림 없음

  5. 종가/기준 판별 로직
     — 15:30 KST 기준으로 종가 확정 여부 자동 판별

  6. 흰 배경 차트 + 검은 외부
     — layout.background 분리, MA·볼린저밴드 색상
       흰 배경 대비 재조정


🐛 해결한 주요 버그

| 증상                              | 원인                                        | 해결                                     |
|-----------------------------------|---------------------------------------------|------------------------------------------|
| 차트 빈 화면 (404 분서)           | from routers 임포트 실패                    | from backend.routers로 변경                  |
| API 응답 빈 데이터                | _ROOT 경로 계산 오류 (parent 4개)           | 3 parent로 수정                          |
| 'N/NaN/NaN 날짜 표시              | BusinessDay/timestamp 분기 없음             | 통합 헬퍼로 3가지 포맷 분기              |
| 정보 패널이 항상 오늘 값만 표시   | _ts2key가 BusinessDay일 때 ts*1000=NaN      | 'year' in t 분기 추가                    |
| 두 차트 따로 움직임 + 줌아웃 공백 | 양방향 구독 피드백 루프                     | fixEdge + 일방향 동기화                  |
| 차트 너비 0 (초기 렌더)           | display:none 상태에서 차트 생성             | status 오버레이 + setTimeout 리사이즈    |


🎨 차트 UI 진화 과정

  v1: 단순 캔들                       → 너무 단조로움
  v2: + 거래량 추가                   → 두 차트가 따로 움직임
  v3: + MA + 볼린저밴드 추가          → 색상이 겹쳐서 안 보임
  v4: 드래그 제한 추가                → 양옆 공백 + 자동 줌인 버그
  v5: fixEdge 옵션 사용               → 안정화 성공
  v6: 팝업 OHLCV 툴팁                 → 차트 가림 단점
  v7: 토스 스타일 좌상단 패널 (최종)  → 가림 없음 + 실시간 갱신
  v8: 흰 배경 + KRX 로고 + 기준시각   → 완성
