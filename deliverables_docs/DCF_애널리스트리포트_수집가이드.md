# DCF 밸류에이션용 — 애널리스트 리포트 수집 가이드

> 목적: 634개 타겟 기업의 애널리스트 리포트 PDF를 받을 때, **어떤 증권사 / 어떤 값**을 봐야 하는지 한눈에. DCF(현금흐름할인법) 계산에 필요한 숫자를 빠짐없이 정리.

---

## 1. DCF 한 줄 원리

미래의 **잉여현금흐름(FCFF)** 을 **할인율(WACC)** 로 현재가치화 → **기업가치(EV)** → 순차입금 차감 → **주주가치** → ÷ 발행주식수 = **적정주가**

```
적정주가 = [ Σ FCFFₜ/(1+WACC)ᵗ  +  잔존가치(TV) ]  −  순차입금
           ─────────────────────────────────────────────────
                              발행주식수
```

---

## 2. ★가장 중요★ FCF vs FCFF — 무엇을 받아야 하나

| 구분 | 정식명칭 | 귀속 대상 | 할인율 | 우리 DCF |
|---|---|---|---|---|
| **FCFF** | 기업잉여현금흐름 (Free Cash Flow to **Firm**) | 채권자 + 주주 전체 | **WACC** | ✅ **이걸 씀** |
| FCFE | 자기자본잉여현금흐름 (Free Cash Flow to **Equity**) | 주주만 | 자기자본비용(Ke) | △ |
| FCF | 잉여현금흐름 (통칭) | 문맥에 따라 다름 | — | 보조 |

- **우리 엔진은 WACC로 할인하므로 정답은 FCFF**입니다.
- 리포트에 "FCF"라고만 적혀 있으면 → **이자비용 차감 전(세후영업이익 기반)인지 확인**. 보통 증권사 표의 "FCF"는 FCFF에 가깝습니다.
- **FCFF가 직접 적힌 리포트가 베스트.** 없으면 아래 구성요소로 직접 계산합니다.

### FCFF 계산식 (둘 중 아무거나)
```
① FCFF = EBIT × (1 − 법인세율) + 감가상각비(D&A) − 자본적지출(CAPEX) − 순운전자본증감(ΔNWC)
② FCFF = 영업활동현금흐름(CFO) + 이자비용 × (1 − 법인세율) − 자본적지출(CAPEX)
```

## 4. "좋은 리포트" 고르는 기준

1. **추정 재무제표 표(Forecast Financials)** 가 향후 2~3년치로 있는 것 ← 1순위 조건
2. **In-depth / Initiation(분석 개시)** 리포트 우선 — 단순 분기 코멘트보다 추정이 훨씬 상세
3. 가능하면 **DCF·FCFF·WACC 가정**이 본문에 적힌 리포트
4. 발간일이 **최근 3~6개월 내** (추정이 최신)
