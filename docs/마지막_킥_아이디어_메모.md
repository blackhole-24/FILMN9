## 핵심 문제 인식

현재 FILMN9는 **회사명 또는 종목코드를 정확히 알아야만 사용 가능**.
→ 주식을 모르는 사람, 상장사가 어떤 회사들인지 모르는 사람은 첫 화면부터 막힘.
→ 사이트에 처음 온 사람이 "이걸 어떻게 써야 하지?" 라는 생각이 드는 구조.

## 아이디어 1 — 메인화면(Tab0) 전면 개편: 시황 대시보드

### 목표
> 처음 온 사람도 "아, 지금 주식 시장이 이렇구나"를 직관적으로 느끼게 해주는 메인화면

### 구현 방향
- 코스피 / 코스닥 지수 실시간 흐름 (라인 차트)
- 오늘 상승/하락 상위 종목 히트맵 or 티커
- 업종별 등락 현황 (색상으로 한눈에: 빨강=하락, 초록=상승)
- 시가총액 상위 10종목 카드 나열
- "요즘 뜨는 산업" 배너 (뉴스 기반 AI 추출 키워드)
- 계절성 알림 (예: "이맘때 오르는 섹터는?")

## 아이디어 2 — 업종/산업 검색 기능 신설

### 목표
> "방산", "반도체", "화장품" 등 키워드만 입력해도 관련 종목 리스트 바로 표시

### 사용자 흐름 예시
```
사용자가 "방산" 입력
→ 유사 업종 자동 매칭 (방산 = 국방, 항공, 방위산업 등)
→ 방산 대장주 TOP 3 카드 (한화에어로스페이스, LIG넥스원 등)
→ 방산 관련 전체 종목 스크롤 리스트
→ 그룹별 탭: [대장주] [재무우량] [미래전망] [현금성 강한 기업]
```

### 검색 키워드 예시 (유사어 매핑 필요)
| 입력 키워드 | 매핑 업종 |
|---|---|
| 방산, 국방, 무기, 항공 | 방위산업 |
| 반도체, 칩, 메모리 | 반도체 |
| 화장품, 뷰티, K-뷰티 | 화장품/생활용품 |
| 건설, 아파트, 주택 | 건설/부동산 |
| 로봇, 자동화, AI로봇 | 로보틱스 |
| 엔터, 아이돌, K-pop | 엔터테인먼트 |
| 통신, 5G, 인터넷 | 통신 |
| 물류, 배송, 택배 | 물류/유통 |
| 석유, 정유, 에너지 | 에너지/화학 |

## 아이디어 3 — 전체 상장사 2,695개 산업 분류 DB 구축

### 필요성
업종 검색 기능을 위해 2,695개 상장사 각각에 산업 태그 부여 필요

### 분류 기준 (우선순위)
1. **WICS 분류** (WISEfn 산업분류 — 한국 주식시장 표준)
2. **DART XBRL 업종코드**
3. **한국거래소(KRX) 업종분류**
4. 뉴스/애널리스트 리포트 기반 보조 태깅

### 분류 방식
- 한 기업이 여러 업종에 걸쳐있을 경우 → **매출 비중 최대 업종**을 주 산업으로 지정
- 부업종은 서브 태그로 병기
- 대장주 지정 기준: 시가총액 또는 거래량 상위 기업

### Task (별도 업무로 등록 필요)
- [ ] WICS 분류 기준으로 2,695개 기업 산업 태그 일괄 매핑
- [ ] 유사어 사전(synonym dict) 구축 (키워드 → 표준 업종명)
- [ ] 업종별 대장주 선정 로직 구현

## 아이디어 4 — AI 시황 브리핑 & 뉴스 경제 해석기

### 목표
> 매일/매주 최신 뉴스를 읽어서, 일반인도 이해할 수 있는 경제 흐름 요약을 제공

### 기능 설계
```
매일 뉴스 수집 (RSS / 네이버 경제 / 한경 / 매경 등)
    ↓
핵심 키워드 추출 (금리, 환율, 유가, 전쟁, 정책 등)
    ↓
경제 지표 해석 엔진
    예) "금리 인상" → 성장주 부담 / 가치주 유리
        "유가 상승" → 정유·화학 수혜 / 항공·물류 부담
        "전쟁 종전" → 건설·방산 주목
        "AI 투자 확대" → 반도체·데이터센터 수혜
    ↓
사용자에게 "요즘 이런 뉴스가 많아요. 이런 섹터를 주목하세요" 형태로 전달
```

### 계절성 / 패턴 분석
- 과거 동일 시기(분기·월) 주가 흐름 패턴 학습
- 예: 1분기 = 실적 시즌, 방어주 관심 / 여름 = 에너지·여행 섹터 강세
- 현재 뉴스 + 과거 패턴 = AI 시황 예측 코멘트

## 아이디어 5 — UX 재설계: 사용자 여정 재정의

### 핵심 질문
> "주식을 전혀 모르는 사람이 우리 사이트에 처음 왔을 때, 손가락 하나하나 어떻게 움직일까?"

### 제안하는 사용자 여정 (User Journey)

```
[1단계] 진입
메인화면에서 시황 한눈에 파악
"아, 오늘 시장이 많이 올랐구나 / 내렸구나"

[2단계] 흥미 유발
"요즘 뜨는 산업: 로봇, 방산" 배너 클릭
→ 관련 종목 리스트 자동 표시

[3단계] 종목 탐색
대장주 카드 클릭
→ 기업 히스토리 브리핑(Tab1) 바로 연결

[4단계] 깊은 분석
Tab2 밸류에이션으로 이동
"이 회사가 지금 비싼 건지 싼 건지 알 수 있다"

[5단계] AI 질문
Tab3 RAG 챗봇으로 이동
"더 궁금한 거 물어보기"
```

### 핵심 설계 원칙
- 사용자가 뭘 검색해야 할지 **몰라도** 시작할 수 있어야 한다
- 클릭 한 번으로 시황 → 업종 → 종목 → 분석까지 이어지는 **자연스러운 흐름**
- 주식 용어 최소화 또는 툴팁으로 설명
