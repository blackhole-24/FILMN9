## 페르소나 개요

FILMN9의 핵심 타깃은 **"주식을 처음 시작하는 일반 투자자"**이다.
아래 3개의 페르소나는 실제 서비스 사용자 인터뷰 및 시장 리서치를 기반으로 정의했다.

| 페르소나 | 이름 | 직군 | 투자 경험 |
|---|---|---|---|
| P1 | 김서연 | 사회 초년생 (마케터) | 입문 (6개월 미만) |
| P2 | 박민준 | 중간관리자 (30대 직장인) | 중급 (3년) |
| P3 | 이지현 | 컨설턴트 / 재무 전문가 | 전문 (분석 능력 보유) |

## 페르소나 1 — 김서연 (주요 타깃)

```
┌─────────────────────────────────────────────────────┐
│  김서연 (가명) | 26세 | 서울 거주                     │
│  직업: 중소기업 마케터 (입사 2년차)                   │
│  월 소득: 270만 원 | 저축 여력: 50만 원/월            │
│  투자 경험: 6개월 (주식 계좌 개설은 했지만 소극적)   │
└─────────────────────────────────────────────────────┘
```

### 배경
- 친구들이 주식 얘기를 많이 해서 계좌를 열었지만, 어디서 시작해야 할지 모름
- 삼성전자 주식 소액 보유 중 (적금 대신 넣어둔 수준)
- 경제 유튜브 가끔 시청, 기사 헤드라인은 읽지만 깊이 이해하지 못함
- "PER이 뭔지는 알겠는데, 이게 높으면 좋은 건지 나쁜 건지 모르겠어요"

### 목표 (Goals)
- 뉴스에서 화제인 기업이 실제로 투자할 가치가 있는지 빠르게 판단하고 싶다
- 주식 얘기가 나올 때 적어도 '아는 척' 할 수 있는 수준이 되고 싶다
- 손해 보지 않으면서 적금보다는 나은 수익을 원한다

### 불편함 (Frustrations)
- 네이버 주식에서 재무 탭을 열면 숫자가 너무 많아 무엇을 봐야 할지 모름
- "이 회사가 왜 좋은지" 설명해주는 곳이 없음
- 증권사 앱은 전문가용 같아서 겁난다
- 유튜버들은 결국 "매수하세요"만 외쳐서 믿기 어렵다

### 행동 패턴
- 스마트폰으로 정보 탐색 (주로 유튜브, 인스타그램 릴스)
- 복잡한 숫자보다 **비주얼, 요약 카드** 선호
- 5분 이상 집중하기 어려움
- 친구나 커뮤니티 추천 종목 관심 많음

### FILMN9 사용 시나리오
```
1. 친구가 "요즘 아모레퍼시픽 좋다더라"는 말을 들음
2. FILMN9에서 "아모레퍼시픽" 검색
3. Tab1 브리핑 카드: "아, 화장품 회사고, 중국 시장 의존도가 높구나"
4. Sankey 다이어그램: "매출이 3.89조인데 순이익이 5,928억이네. 흑자는 확실히 내고 있군"
5. Tab2: "적정가 11만원, 현재 9만원... 저평가라는 건가?"
6. "WACC가 9.25%라는 건 뭔지 모르겠지만, 파란 배지 떴으니 믿어볼게"
```

### 핵심 니즈 요약
> "복잡한 건 몰라도 돼. 이 회사 투자해도 될지 안 될지만 알려줘."

## 페르소나 2 — 박민준 (핵심 타깃)

```
┌─────────────────────────────────────────────────────┐
│  박민준 (가명) | 34세 | 경기도 거주                   │
│  직업: IT 기업 팀장 (7년차)                          │
│  월 소득: 520만 원 | 월 투자금: 200만 원              │
│  투자 경험: 3년 (주식 + 부동산 관심)                 │
└─────────────────────────────────────────────────────┘
```

### 배경
- 주식 투자 3년 차, 손익 그래프가 들쑥날쑥해서 "제대로 공부해야겠다"고 결심
- PER, PBR, EPS 정도는 알지만 DCF는 들어본 적만 있음
- 회사에서 IT 프로젝트 관리 하기 때문에 **데이터 기반 의사결정** 익숙
- 주식 공부를 하고 싶은데 퇴근 후 시간이 없음 (아이 2명)

### 목표 (Goals)
- 내가 갖고 있는 종목이 지금 비싼 건지 싼 건지 **객관적 기준**으로 알고 싶다
- 투자 결정을 감이 아닌 **수치 근거**로 내리고 싶다
- 새로운 종목 발굴 시 20~30분 안에 기초 분석 마치고 싶다

### 불편함 (Frustrations)
- 애널리스트 리포트를 구하긴 했는데 가정 근거를 모르니 그냥 믿어야 함
- 엑셀 DCF 모델을 만들어봤지만 데이터 수집에 3시간 소요
- 증권사 MTS의 재무 데이터는 있지만 밸류에이션 계산 기능 없음
- PER 낮은 종목을 샀는데 더 떨어지는 경험 반복 → "뭔가 놓치고 있는 게 있다"

### 행동 패턴
- 퇴근 후 30분 ~ 1시간 종목 분석
- 여러 소스를 비교 검토 (증권사 리포트 + 뉴스 + 커뮤니티)
- 스프레드시트 활용에 익숙
- 신뢰할 수 있는 **수치 근거** 중요시

### FILMN9 사용 시나리오
```
1. NAVER 주가가 많이 떨어진 걸 확인, 저평가인지 확인하고 싶음
2. FILMN9에서 "NAVER" 검색
3. Tab2: Base 적정가 ₩347,238 vs 현재 ₩199,xxx → +74.1% 업사이드
4. WACC 탭: "무위험이자율 3.2%, 베타 0.87... 합리적인 가정이네"
5. 민감도 히트맵: "WACC 1% 올라도 업사이드 50% 이상이면 안전마진 충분하겠다"
6. Tab1 브리핑: "AI 검색 광고 의존도가 높은 게 리스크구나" 확인
7. 투자 결정: 분할 매수 시작
```

### 핵심 니즈 요약
> "근거 있는 숫자로 판단하고 싶다. 계산 과정도 검증하고 싶다."

## 페르소나 3 — 이지현 (보조 타깃 / 검증자)

```
┌─────────────────────────────────────────────────────┐
│  이지현 (가명) | 31세 | 서울 거주                    │
│  직업: 경영 컨설팅 펌 어소시에이트 (4년차)           │
│  월 소득: 650만 원 | 투자 방식: 자체 분석 + 투자      │
│  투자 경험: 6년 (DCF 모델 직접 구성 가능)           │
└─────────────────────────────────────────────────────┘
```

### 배경
- 전략 컨설턴트로 기업 가치 평가 업무 경험 있음
- 개인 투자용 DCF 엑셀 모델 보유 (직접 만든 것)
- "이 서비스가 제대로 된 계산을 하는지" 검증하는 시각으로 접근
- 일반인에게 투자 방법 추천해달라는 요청을 자주 받음

### 목표 (Goals)
- 자신이 직접 구성한 모델과 비교해서 서비스의 신뢰도를 검증하고 싶다
- 빠른 스크리닝 도구로 활용 (전체 시장 → 관심 종목 필터링)
- 투자 공부 중인 지인에게 추천할 수 있는 서비스인지 평가

### 불편함 (Frustrations)
- 대부분 핀테크 서비스가 "블랙박스" — 어떻게 계산하는지 모름
- WACC 가정이 보수적인지 낙관적인지 알 수 없으면 결과를 신뢰 못 함
- 입력 변수를 바꿔볼 수 없는 정적인 서비스는 의미 없음

### FILMN9 사용 시나리오
```
1. WACC 탭 클릭: Rf, β, MRP, Kd, t 각각 확인
2. "β = 0.87... 내가 계산한 값이랑 비슷하네. 신뢰할 수 있겠다"
3. 민감도 탭: "WACC 9.25% 기준 셀이 Base네. 가정 명확히 보여주는 건 좋아"
4. 삼성전기 진입: DCF Invalid 경고 확인
5. "Y+1 FCFF 음수 자동 감지까지 하는구나. 이거 제대로 만든 서비스다"
6. 지인에게 추천: "이거 써봐, WACC 계산 다 보여줘서 공부도 되고 편해"
```

### 핵심 니즈 요약
> "계산 근거를 보여줘야 신뢰할 수 있다. 블랙박스 서비스는 쓰지 않는다."

## 페르소나 종합 인사이트

### 공통 니즈
1. **시간 절약**: 기업 분석에 소요되는 시간 최소화
2. **신뢰성**: 계산 근거와 데이터 출처 명확
3. **이해 가능성**: 전문 용어도 쉽게 설명되어야 함
4. **시각화**: 숫자보다 차트와 다이어그램으로 직관적 이해

### 타깃 우선순위

```
      사용 빈도 높음
           ▲
  P2 박민준│ ← 핵심 타깃
   (중급) │
           │   P1 김서연 ← 주 볼륨 타깃
           │   (입문자)
           │                   P3 이지현
           │                   (전문가)
           ────────────────────────────▶
      분석 요구 낮음            분석 요구 높음
```

### 설계 원칙 (페르소나 기반)

| 원칙 | P1 적용 | P2 적용 | P3 적용 |
|---|---|---|---|
| 요약 카드 우선 노출 | ✅ 핵심 | ✅ 효율적 | △ 스킵 |
| 수치 근거 전 과정 공개 | △ 참고 | ✅ 중요 | ✅ 필수 |
| 경고·주의 자동 표시 | ✅ 보호 | ✅ 의사결정 | ✅ 검증 |
| 전문 용어 툴팁 제공 | ✅ 필수 | △ 참고 | ✗ 불필요 |
| 시각화 (차트·다이어그램) | ✅ 핵심 | ✅ 효율 | ✅ 검증 |
