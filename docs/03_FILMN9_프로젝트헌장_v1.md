## 2. 프로젝트 목적 (Purpose)

### 2.1 비즈니스 목적
개인 투자자(일반인)를 위한 기업 분석 자동화 서비스를 PoC 형태로 구현하여,
서비스 실현 가능성과 시장 수요를 KPMG AI Lab 내부에 실증한다.

### 2.2 전략적 목적
- LLM + 공시 데이터(DART) + 금융 모델링의 결합 가능성 검증
- B2C 개인 투자자 서비스 영역에서의 AI 활용 사례 창출
- 이후 스프린트에서 상용 서비스 전환의 기반 마련

### 2.3 PoC 성공 정의
```
✅ 3개 종목(아모레퍼시픽, 삼성전기, NAVER)에 대해
   Tab1(기업 브리핑) + Tab2(밸류에이션) + Sankey(손익 흐름)를
   5분 데모 시연에서 오류 없이 작동시키는 것
```

## 4. 프로젝트 범위 (Scope)

### 4.1 포함 범위 (In Scope)

**데이터 & 인프라**
- DART API 연동 및 재무 데이터 수집 (3개 종목)
- SQLite 로컬 DB 구성
- FastAPI 백엔드 서버 (:8000)
- Next.js 프론트엔드 (:3000)

**기능**
- 종목 검색 (회사명 / 종목코드)
- Tab1: 주가 차트, 재무 지표 카드, AI 히스토리 브리핑 3카드, Sankey 다이어그램
- Tab2: DCF 3시나리오, WACC 자동 산출, 민감도 히트맵, DCF 유효성 검증, 멀티플 역산
- Tab3: SWOT / RAG 챗봇 UI (데이터 연결 Sprint 2)

## 10. 의존성 및 제약

### 10.1 외부 의존성
- DART OpenAPI 정상 운영 여부
- OpenAI API 가용성 (GPT-4o)
- FinanceDataReader / yfinance 주가 데이터 품질

### 10.2 기술 제약
- 현재 SQLite 사용 → 동시 접속 1명 기준 (PoC 적합)
- Sankey는 사전 HTML 파일 방식 → 실시간 갱신 불가 (PoC 적합)
- Tab3 챗봇은 UI만 구현 (데이터 연결 Sprint 2)

### 10.3 비즈니스 제약
- 금융투자업 관련 법규 미적용 (참고용 서비스, 투자 권유 아님)
- 개인정보 수집 없음 (비로그인 서비스)
