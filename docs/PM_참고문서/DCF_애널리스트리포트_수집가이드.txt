[ 1 ] DCF 한 줄 원리
--------------------------------------------------------------------------------
  미래의 잉여현금흐름(FCFF)을 할인율(WACC)로 현재가치화
   -> 기업가치(EV) -> 순차입금 차감 -> 주주가치 -> ÷발행주식수 = 적정주가

        Σ FCFFt/(1+WACC)^t  +  잔존가치(TV)  −  순차입금
  적정주가 = ----------------------------------------------------
                           발행주식수


[ 2 ] ★가장 중요★  FCF vs FCFF — 무엇을 받아야 하나
--------------------------------------------------------------------------------
  구분    정식명칭                          귀속대상        할인율    우리DCF
  ------  --------------------------------  --------------  --------  -------
  FCFF    기업잉여현금흐름(to Firm)         채권자+주주     WACC      ✅ 이것
  FCFE    자기자본잉여현금흐름(to Equity)   주주만          Ke         △
  FCF     잉여현금흐름(통칭)                문맥별          —         보조

  => 우리 엔진은 WACC로 할인하므로 정답은 'FCFF' 입니다.
  => 리포트에 "FCF"만 있으면, 이자비용 차감 전(세후영업이익 기반)인지 확인.
     (보통 증권사 표의 FCF는 FCFF에 가깝습니다)
  => FCFF가 직접 적힌 리포트가 베스트. 없으면 아래 식으로 직접 계산:

     FCFF = EBIT×(1−법인세율) + 감가상각비(D&A) − 자본적지출(CAPEX) − 순운전자본증감(ΔNWC)
     또는
     FCFF = 영업활동현금흐름(CFO) + 이자비용×(1−법인세율) − 자본적지출(CAPEX)


[ 3 ] 리포트에서 "찾아야 할 값" 전체 목록  ( ✅필수 / ⭐있으면매우좋음 / △보조 )
--------------------------------------------------------------------------------
 A. 미래 추정치 (Forward, 최소 3년치 = 2025E·2026E·2027E)
     1. 매출액 추정 (Revenue/Sales) ................................. ✅
     2. 영업이익 추정 (Operating Profit / EBIT) ..................... ✅
     3. 영업이익률 (OPM) ............................................ △
     4. 당기순이익 추정 (Net Income) ................................ ✅
     5. EBITDA 추정 ................................................. ⭐
     6. 감가상각비 (D&A) ............................................ ✅
     7. 자본적지출/설비투자 (CAPEX) ................................. ✅
     8. 순운전자본 / 증감 (Working Capital / ΔNWC) .................. ⭐
     9. FCF 또는 FCFF 추정치 (Free Cash Flow) ...................... ⭐ (직접 있으면 계산 생략)

 B. 할인율(WACC) 구성요소
    10. 베타 (Beta, β) ............................................. ✅
    11. 부채비율 / 자본구조 (D/E, 차입금/자기자본) ................. ✅
    12. 이자비용 · 평균 차입이자율 (Kd, 세전 타인자본비용) ......... ⭐
    13. 유효 법인세율 (Effective Tax Rate) ......................... ✅

 C. 주주가치 환산용
    14. 순차입금 (= 총차입금 − 현금성자산, Net Debt) ............... ✅
    15. 발행주식수 (Shares Outstanding) ............................ ✅
    16. 목표주가 / 적정주가 (애널리스트 산출, 우리결과 검증용) ..... ⭐
    17. 투자의견 (Buy/Hold/Sell) ................................... △

  ※ 핵심: "추정 재무제표(Forecast)" 표에 1·2·4·6·7이 향후 3년치로 있고,
          거기에 10·14·15까지 있으면 그 리포트 하나로 DCF가 거의 완성됩니다.


[ 4 ] "좋은 리포트" 고르는 기준
--------------------------------------------------------------------------------
  1. 추정 재무제표 표(Forecast)가 향후 2~3년치로 있는 것  <-- 1순위 조건
  2. In-depth / Initiation(분석 개시) 리포트 우선 (분기 코멘트보다 추정 상세)
  3. 가능하면 DCF·FCFF·WACC 가정이 본문에 적힌 리포트
  4. 발간일이 최근 3~6개월 내 (추정이 최신)
