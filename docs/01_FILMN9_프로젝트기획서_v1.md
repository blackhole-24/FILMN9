# FILMN9 프로젝트 기획서 v1.0

> 작성일: 2026-05-24 | 작성자: FILMN9 팀 | 상태: 확정 (PoC 기준)

---

## 1. 프로젝트 개요

### 1.1 프로젝트명
**FILMN9** — *Financial Intelligence for Light-Minded Normal Investors*

### 1.2 한 줄 정의
> "주식 투자를 처음 시작하는 일반 투자자를 위한 AI 기반 기업 분석 자동화 플랫폼"

### 1.3 핵심 가치 제안 (Value Proposition)

| 기존 방식의 문제 | FILMN9의 해결 |
|---|---|
| 사업보고서 수백 페이지를 직접 읽어야 함 | AI가 핵심 내용을 3개 카드로 자동 요약 |
| DCF 모델 구성에 수일 소요 | 검색 한 번으로 5초 내 자동 산출 |
| 애널리스트 리포트는 기관 전용 | 누구나 무료로 동일 수준 정보 접근 |
| 계산 근거를 알 수 없음 | WACC·FCFF 전 과정 투명하게 공개 |
| 어느 방법론이 맞는지 모름 | DCF 유효성 자동 검증 + 대안 방법론 안내 |

## 2. 배경 및 필요성

### 2.1 시장 현황
- 국내 주식 계좌 보유자: **약 1,400만 명** (2025년 기준)
- 한국 개인투자자 직접 투자 비율: 전체 거래대금의 약 **62%** (KRX 통계)
- 기업 재무 분석 능력 보유 비율: 전체 투자자의 **약 5% 미만** (추정)
- 나머지 95%: 뉴스, 커뮤니티, 직관에 의존해 투자 의사결정

### 2.2 기존 서비스의 한계

| 서비스 유형 | 한계 |
|---|---|
| 증권사 HTS/MTS | 차트 중심, 기업 분석 기능 미흡 |
| 네이버/카카오 주식 | 기본 재무 지표만 제공, 밸류에이션 없음 |
| 애널리스트 리포트 | 기관·증권사 계정 필요, 비전문가 이해 어려움 |
| 기업 DART 공시 | 원문 그대로 노출, 비전문가 접근 불가 |
| 개인 투자 블로그 | 정보 신뢰성 불분명, 최신성 보장 없음 |

### 2.3 기회 요소
- LLM 기술 성숙: GPT-4o, Claude 3.5 등 고성능 모델 API 상용화
- DART 공개 API: 전 상장사 사업보고서 무료 접근 가능
- RAG 기술: 긴 공시 문서를 문맥 기반으로 검색·요약 가능
- 개인 투자자 정보 비대칭 해소 수요 급증

## 3. 목표

### 3.1 서비스 목표
1. **접근성**: 주식을 모르는 사람도 기업 분석 결과를 5분 안에 이해할 수 있다
2. **신뢰성**: 애널리스트 수준의 정확도로 DCF·멀티플 밸류에이션을 자동 산출한다
3. **투명성**: 어떤 데이터로, 어떤 공식으로 계산됐는지 전 과정을 공개한다
4. **확장성**: 코스피·코스닥 전 상장사 2,695개에 동일한 분석을 제공한다

### 3.2 PoC 정량 목표

|---|---|
| 지원 종목 수 | 3종목 (아모레퍼시픽, 삼성전기, NAVER) |
| 검색 → 분석 화면 로딩 | 5초 이내 |
| DCF 산출 오차 | DART 공시 기준 ±5% 이내 |

## 4. 서비스 범위 (Scope)

### 4.1 PoC 범위 (In Scope)

**Tab1 — 기업 히스토리 브리핑**
- 주가 차트 (캔들스틱 + 이동평균선 + 거래량)
- 핵심 재무 지표 카드 (시총, PER, PBR, EPS 등)
- AI 히스토리 브리핑 3카드 (기업 개요 / 사업 모델 / 주가 영향 요인)
- 손익 흐름 Sankey 다이어그램

**Tab2 — 밸류에이션**
- DCF 모델 (5개년 FCFF + 터미널 밸류)
- Bear / Base / Bull 3가지 시나리오
- WACC 자동 산출 (무위험이자율, 베타, MRP, 타인자본비용)
- 민감도 분석 히트맵 (WACC × 터미널성장률)
- DCF 유효성 자동 검증 + 경고 배너
- 멀티플 역산 적정가 (EV/EBITDA, P/E, P/B)

**Tab3 — AI 종합분석** *(UI 구현, 데이터 연결 예정)*
- SWOT 자동 생성
- RAG 기반 사업보고서 챗봇

### 4.2 현재 제외 범위 (Out of Scope)

| 항목 | 제외 이유 |

| 실시간 주가 스트리밍 | 유료 API 필요, PoC 불필요 |
| 전체 2,695종목 | 데이터 수집 공수 과다 |

## 5. 주요 기능 상세

### 5.1 종목 검색
- 입력: 회사명(한글) 또는 종목코드(6자리)
- 자동완성 + 유사어 매칭
- 검색 결과 → Tab1 즉시 진입

### 5.2 Tab1 — 기업 히스토리 브리핑

#### 주가 차트
- 캔들스틱 (시가/고가/저가/종가)
- 이동평균선: MA5, MA20, MA60, MA120
- 거래량 바 차트 (하단 영역)
- 기간 선택: 1M / 3M / 6M / 1Y / ALL

#### 핵심 재무 지표 카드
- 시가총액, 현재주가, 전일대비
- PER, PBR, EPS, BPS
- 배당수익률, 영업이익률, 부채비율
- 주요 주주 현황

#### AI 히스토리 브리핑 (3카드)
- **기업 개요**: 설립연도, 주요 사업, 계열사 관계
- **사업 모델**: 수익 구조, 주요 제품/서비스, 고객군
- **주가 영향 요인**: 해당 기업 주가를 움직이는 핵심 변수 3~5개
- 데이터 소스: DART 사업보고서 + LLM(GPT-4o) 분석

#### 손익 Sankey 다이어그램
- 매출액 → 매출원가 → 매출총이익 → 판관비 → 영업이익 → 순이익
- 서비스업 자동 감지: 영업비용 통합 구조 특별 처리 (NAVER 등)
- 기준: 최근 사업연도 연결 재무제표 (DART)
- 단위: 억 / 조원

### 5.3 Tab2 — 밸류에이션

#### DCF 모델
- 추정 기간: Y+1 ~ Y+5 (5개년)
- 변수: FCFF = EBIT × (1-t) + D&A - CAPEX - ΔNWC
- 터미널 밸류: TV = FCFF₅ × (1+g) / (WACC - g)
- 기업가치 = PV(FCFF₁~₅) + PV(TV)
- 주당 적정가 = (기업가치 - 순차입금) / 발행주식수

#### WACC 산출 (자동)
```
WACC = E/(E+D) × Ke + D/(E+D) × Kd × (1-t)

Ke = Rf + β × MRP
- Rf: 국고채 10년물 수익률 (실데이터)
- β: 최근 2년 주가 회귀분석 결과 (실데이터)
- MRP: 한국 시장 기준 5.5%

Kd = 금융비용 / 총차입금 (DART 실데이터)
t: 실효세율 (DART 실데이터)
```

#### 시나리오
| 구분 | 매출성장률 | 영업이익률 | 터미널성장률 |
|---|---|---|---|
| Bear | 보수적 | 현재 미만 | 1.0% |
| Base | 중립적 | 현재 유지 | 2.0% |
| Bull | 낙관적 | 현재 초과 | 3.0% |

#### DCF 유효성 검증
- 조건: Y+1 FCFF < 0
- 결과: 노란 경고 배너 자동 표시
- 안내: "DCF 대신 멀티플 역산가를 우선 참고 권장"
- 이유: 초기 FCFF 음수 시 DCF 왜곡 발생

#### 민감도 히트맵
- X축: 터미널성장률 (0.0% ~ 4.0%, 0.5% 단위)
- Y축: WACC (Base ± 2.0%, 0.5% 단위)
- 색상: 진한 파랑(저평가) ↔ 흰색(공정가치) ↔ 진한 빨강(고평가)
- Base 시나리오 셀: 파란 테두리 표시

#### 멀티플 역산
- EV/EBITDA: 피어 그룹 평균 멀티플 × EBITDA - 순차입금
- P/E: 피어 그룹 평균 PER × EPS
- P/B: 피어 그룹 평균 PBR × BPS

### 5.4 Tab3 — AI 종합분석

#### SWOT 자동 생성
- 강점(S): 재무 안정성, 시장 지위, 기술력
- 약점(W): 비용 구조, 의존도 리스크
- 기회(O): 시장 트렌드, 규제 변화 수혜
- 위협(T): 경쟁사, 거시경제 리스크
- 소스: DART 사업보고서 + 최신 뉴스 + LLM 생성

#### RAG 기반 챗봇
- 벡터 DB: 사업보고서 청킹 + 임베딩 저장
- 검색: 질문 → 유사 청크 추출
- 생성: 추출 청크 기반 답변 + 인용 출처 표시
- 예: "아모레퍼시픽의 중국 매출 비중은?" → 사업보고서 해당 항목 인용

## 6. 기술 스택

### 6.1 백엔드

| 구분 | 기술 | 용도 |
|---|---|---|
| 웹 프레임워크 | FastAPI (Python 3.11) | API 서버, :8000 |
| 데이터베이스 | SQLite → PostgreSQL | 재무 데이터 저장 |
| LLM | OpenAI GPT-4o | 브리핑 생성, SWOT |
| 임베딩 | text-embedding-3-small | 사업보고서 벡터화 |
| 벡터 DB | ChromaDB → Pinecone | RAG 검색 |
| 데이터 수집 | DART Open API | 공시, 재무제표 |
| 주가 데이터 | FinanceDataReader, yfinance | 주가/거래량 |

### 6.2 프론트엔드

| 구분 | 기술 | 용도 |
|---|---|---|
| 웹 프레임워크 | Next.js 14 (App Router) | UI, :3000 |
| 스타일링 | Tailwind CSS | 반응형 레이아웃 |
| 컴포넌트 | shadcn/ui | 공통 UI 컴포넌트 |
| 차트 | Recharts | 주가 차트, 재무 차트 |
| Sankey | Plotly.js | 손익 흐름 다이어그램 |
| 상태관리 | React Query (TanStack) | 서버 상태 캐싱 |
| UI 생성 | v0.dev (Vercel AI) | 초기 컴포넌트 생성 |

### 6.3 인프라 (PoC)

| 구분 | 구성 |
|---|---|
| 실행 환경 | 로컬 PC (Windows) |

| 데이터 파이프라인 | Python 스크립트 (build_sankey.py 등) |
