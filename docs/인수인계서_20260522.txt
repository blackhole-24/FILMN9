4. 서버 재시작 및 화면 확인 방법
----------------------------------------------------------------

  1) start.bat 더블클릭 (원클릭 기동)
     또는 수동 실행:
       터미널1: conda activate FILMN9_env
                uvicorn backend.main:app --reload --port 8000
       터미널2: cd frontend && npm run dev

  2) 브라우저 접속:
       프론트엔드: http://localhost:3000
       API 문서:   http://localhost:8000/docs
       밸류에이션 API 테스트:
         http://localhost:8000/api/valuation/090430
         http://localhost:8000/api/valuation/009150
         http://localhost:8000/api/valuation/035420

  3) 확인 포인트:
       Tab1: 히스토리 브리핑 카드 렌더링 여부
       Tab2: Hero 영역 "✓ 실데이터" 배지 표시 여부
       Tab2: Bear/Base/Bull 카드 실수치 표시 여부
       Tab2: 민감도 히트맵 Base 셀 파란 테두리 위치

5. 이슈 및 에러 사항
----------------------------------------------------------------

  [에러]
  - 밸류에이션 결과 파일 구조가 설계 시 예상과 달라
    관련 코드 전면 재작성 필요했음
  - 특정 종목의 DCF 계산이 재무 특성상 유효하지 않다고
    판정됨 → 화면 경고 표시 미구현 상태

  [고려사항]
  - 일부 종목의 산출 적정가와 실제 현재 주가 간 괴리가 큼
    → 데모 시 사전 설명 준비 필요
  - RAG 챗봇은 현재 Mock 응답 상태
    → 데모 전 실데이터 연결 가능 여부 불확실

  [개선할 점]
  - 팀원 간 파일 구조·단위·명칭을 사전에 문서로 합의하면
    불필요한 재작업을 줄일 수 있음
  - 코드 작성 후 즉시 화면으로 확인하는 습관
    → 문제 조기 발견 가능

6. 주요 파일 경로 정리
----------------------------------------------------------------

  api/main.py                          : FastAPI 앱 + 라우터 등록
  api/routers/valuation.py             : 밸류에이션 API (오늘 전면 재작성)
  api/routers/overview.py              : 종합 데이터 API (히스토리 폴백 추가)
  frontend/app/stock/[code]/page.tsx : 메인 화면 (Tab1·Tab2 수정)
  data/parsed_history/                 : 히스토리 브리핑 JSON (3종목)
  data/valuation_results/              : 밸류에이션 결과 JSON (3종목 × 6파일)
  data/embeddings/                     : 사업보고서 임베딩 파일 저장 위치
  docs/AI_기능_4종_설계서_v1.0.html    : AI 기능 설계서
