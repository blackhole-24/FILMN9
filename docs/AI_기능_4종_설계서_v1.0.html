1
🤖 SWOT 자동분석
Auto SWOT Analysis via LLM
GPT-4o SQLite
기능 개요

종목 상세 페이지 진입 시 재무제표·공시·주가 데이터를 자동으로 구조화해 GPT-4o에 전달, Strengths / Weaknesses / Opportunities / Threats 4분면을 한국어로 자동 생성한다.

결과는 SQLite에 캐싱(TTL 24h)하여 동일 종목 재진입 시 API 재호출 없이 즉시 반환한다.

입력 데이터 구성
  • 최근 3개년 매출·영업이익·순이익 (SQLite financials)
  • 영업이익률·부채비율·유동비율 (SQLite health_ratios)
  • 최근 공시 10건 제목 (SQLite disclosures)
  • 주가 52주 고저·등락률 (SQLite ohlcv)
  • 기업 업종·시총 (SQLite company_info)

📅 모닝루틴 브리핑
Morning Routine Automated Briefing
GPT-4o Scheduler
기능 개요

사용자가 관심 종목을 등록해 두면, 매일 오전 7시에 전날 주가 동향·신규 공시·주요 재무 변화를 LLM이 자동으로 요약해 개인화 브리핑을 생성한다.

MongoDB histories 컬렉션에 저장된 히스토리 데이터와 SQLite OHLCV·공시를 결합하여 "어제 무슨 일이 있었는지"를 3~5문장으로 압축 제공.

브리핑 구성 요소
  • 주가 요약 — 전일 등락·거래량 이상 여부
  • 신규 공시 — 전일 공시 제목 + 한줄 요약
  • 재무 이벤트 — 실적 발표·배당·증자 등 캘린더
  • 히스토리 컨텍스트 — 같은 날 과거 주요 사건 (MongoDB)
  • AI 한줄 진단 — "오늘 주목해야 할 포인트"

📊 밸류에이션 AI 어시스트
Valuation AI Assistant
GPT-4o DCF JSON
기능 개요

밸류에이션 파트 run_valuation.py가 산출한 DCF·WACC 결과 JSON을 컨텍스트로 제공하여, "왜 이 적정가가 나왔나?", "WACC가 높으면 어떻게 되나?", "Bear case 가정은?" 등 일반투자자의 자연어 질문에 GPT-4o가 구체적으로 답변한다.

복잡한 재무 모델을 비전문가도 이해할 수 있도록 쉽게 설명하는 것이 핵심 목적.

활용 가능한 컨텍스트 (valuation JSON)
  • DCF 5개년 FCFF 테이블 전체
  • WACC 구성 요소 (Rf, β, ERP, Ke, Kd)
  • Bear/Base/Bull 시나리오 가격·상승여력
  • 민감도 매트릭스 (WACC × g)
  • 토네이도 분석 (변수별 영향도)
  • 피어 베타 비교 (Hamada 조정)
