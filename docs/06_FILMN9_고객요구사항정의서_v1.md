## 1. 문서 목적 및 범위

### 1.1 목적

본 문서는 FILMN9 서비스의 고객 및 사용자 요구사항을 체계적으로 정의하고, 개발팀과 이해관계자 간의 요구사항에 대한 공통 이해를 확립하는 것을 목적으로 한다.

본 문서에서 정의하는 요구사항은 다음의 근거를 기반으로 작성되었다.

- 사용자 페르소나 분석 (P1 김서연 / P2 박민준 / P3 이지현)
- KPMG AI Lab 내부 피드백
- 국내 개인 투자자 서비스 벤치마크 분석
- PoC 개발 과정에서 도출된 요구사항

### 1.2 적용 범위

| 구분 | 내용 |
|---|---|
| 대상 시스템 | FILMN9 웹 서비스 (FastAPI 백엔드 + Next.js 프론트엔드) |
| 적용 버전 | PoC v1.0 (2026-05-26 데모 기준) |
| 지원 종목 | 아모레퍼시픽(090430), 삼성전기(009150), NAVER(035420) |
| 제외 범위 | 모바일 앱, 실시간 거래 연동, 사용자 인증 |

### 1.3 용어 정의

| 용어 | 정의 |
|---|---|
| DCF | Discounted Cash Flow. 미래 현금흐름을 현재가치로 환산해 기업 적정가를 산출하는 밸류에이션 방법론 |
| WACC | Weighted Average Cost of Capital. 자기자본비용과 타인자본비용의 가중평균으로 산출하는 할인율 |
| FCFF | Free Cash Flow to Firm. 기업 전체 잉여현금흐름 |
| DART | Data Analysis, Retrieval and Transfer System. 금융감독원 전자공시시스템 |
| Sankey | 흐름의 규모를 너비로 표현하는 흐름 다이어그램 |
| RAG | Retrieval-Augmented Generation. 문서 검색 기반 LLM 답변 생성 기술 |
| 피어 그룹 | 동일 업종 유사 기업군 |
| PoC | Proof of Concept. 개념 검증용 프로토타입 |

## 4. 사용자 요구사항 (User Requirements)

사용자 요구사항은 각 페르소나가 시스템을 통해 달성하고자 하는 목표를 기술한다.

### 4.1 P1 김서연 — 입문 투자자

| ID | 사용자 요구사항 | 우선순위 |
|---|---|---|
| UR-01 | 회사 이름만 입력하면 바로 분석 결과를 볼 수 있어야 한다 | 필수 |
| UR-02 | 이 회사가 지금 투자할 만한지 아닌지를 한눈에 파악할 수 있어야 한다 | 필수 |
| UR-03 | 주식 전문 용어가 나올 때 쉬운 설명이 함께 제공되어야 한다 | 높음 |
| UR-04 | 숫자보다 차트나 그래프로 정보를 이해할 수 있어야 한다 | 높음 |
| UR-05 | 이 회사가 어떤 회사인지 배경 설명을 쉽게 읽을 수 있어야 한다 | 필수 |
| UR-06 | 화면이 복잡하지 않고 단계별로 정보가 흘러야 한다 | 높음 |

### 4.2 P2 박민준 — 중급 투자자

| ID | 사용자 요구사항 | 우선순위 |
|---|---|---|
| UR-07 | DCF 기반 적정 주가를 자동으로 확인할 수 있어야 한다 | 필수 |
| UR-08 | WACC 계산에 사용된 각 변수(Rf, β, MRP, Kd)를 확인할 수 있어야 한다 | 필수 |
| UR-09 | Bear / Base / Bull 시나리오별 적정가를 비교할 수 있어야 한다 | 필수 |
| UR-10 | WACC나 성장률이 달라질 때 적정가 변화를 시뮬레이션할 수 있어야 한다 | 높음 |
| UR-11 | 해당 기업의 주가에 영향을 미치는 핵심 요인들을 알 수 있어야 한다 | 높음 |
| UR-12 | 멀티플(EV/EBITDA, P/E, P/B) 기반 적정가도 함께 확인할 수 있어야 한다 | 높음 |

### 4.3 P3 이지현 — 재무 전문가

| ID | 사용자 요구사항 | 우선순위 |
|---|---|---|
| UR-13 | WACC 계산의 모든 입력값과 산출 과정을 항목별로 확인할 수 있어야 한다 | 필수 |
| UR-14 | DCF 모델의 신뢰도 판단 근거(FCFF 양/음수)를 명확히 알 수 있어야 한다 | 필수 |
| UR-15 | 각 수치의 데이터 출처(DART 공시 기준)를 확인할 수 있어야 한다 | 필수 |
| UR-16 | DCF가 적합하지 않은 경우 대안 방법론이 자동으로 제시되어야 한다 | 필수 |
| UR-17 | 연도별 FCFF 추정값과 할인 계수, 현재가치를 테이블로 확인할 수 있어야 한다 | 높음 |
