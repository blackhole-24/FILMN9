[작업 순서 — 위에서부터 차례대로 수행]
================================================================

────────────────────────────────────────────────────────────────
STEP 1. 프로젝트 폴더 확인 및 의존성 설치
────────────────────────────────────────────────────────────────

  Bash 도구로:
  > cd C:\Users\<휘주님>\FILMN9
  > python -m venv venv
  > venv\Scripts\activate
  > pip install -r requirements.txt

  핵심 패키지:
  - pymongo>=4.6
  - fastapi
  - uvicorn
  - python-dotenv
  - openai
  - pandas


────────────────────────────────────────────────────────────────
STEP 2. .env 파일 확인
────────────────────────────────────────────────────────────────

  Read 도구로 .env 파일 내용 확인:
  > Read C:\Users\<휘주님>\FILMN9\.env

  필수 키:
    MONGO_URI=mongodb+srv://<USER>:<PASS>@<CLUSTER>.mongodb.net/...
    MONGO_DB=filmn9
    MONGO_COLLECTION=histories

  파일이 없으면 Write 도구로 생성. USER/PASS/CLUSTER는
  Atlas 콘솔에서 휘주님이 직접 복사해 채워넣을 것.


────────────────────────────────────────────────────────────────
STEP 3. MongoDB 연결 테스트
────────────────────────────────────────────────────────────────

  Bash 도구로:
  > python db/test_mongo.py

  성공 출력 패턴:
    [OK] MongoDB 연결 성공
    [OK] filmn9.histories 컬렉션 접근 가능

  실패 시 에러 메시지에 따라 분기:

  분기 A. TLSV1_ALERT_INTERNAL_ERROR
    → STEP 4-1 진행

  분기 B. ServerSelectionTimeoutError (네트워크 차단)
    → STEP 4-2 진행

  분기 C. Authentication failed (인증 실패)
    → 휘주님께 비밀번호 재확인 요청


────────────────────────────────────────────────────────────────
STEP 4-1. TLS 에러 해결 (순서대로 시도)
────────────────────────────────────────────────────────────────

  ① pymongo + certifi 업그레이드:
  > pip install --upgrade pymongo certifi

  ② 다시 test_mongo.py 실행. 성공하면 STEP 5로.

  ③ 안 되면 .env의 MONGO_URI 끝에 옵션 추가:
     기존: ...mongodb.net/?retryWrites=true&w=majority
     변경: ...mongodb.net/?retryWrites=true&w=majority&tls=true&tlsAllowInvalidCertificates=false&directConnection=false

  ④ 안 되면 SRV 대신 표준 연결 문자열 사용:
     Atlas 콘솔 → Connect → Drivers → Connection String Only
     → 휘주님이 복사한 mongodb://... 문자열로 교체

  ⑤ 모두 안 되면 STEP 6 (폴백 모드)로 직행.


────────────────────────────────────────────────────────────────
STEP 4-2. 네트워크 차단 해결
────────────────────────────────────────────────────────────────

  ① 휘주님께 Atlas 콘솔 확인 요청 (자동 처리 불가):
    - Network Access → IP Access List → 0.0.0.0/0 Active 상태?
    - Database → 클러스터 상태 Running? (Paused면 RESUME)

  ② 백신·방화벽 SSL 검사 비활성화 안내

  ③ 그래도 안 되면 STEP 6 (폴백 모드)로 직행.


────────────────────────────────────────────────────────────────
STEP 5. briefs_final.zip 적재 (Mongo 연결 성공 시)
────────────────────────────────────────────────────────────────

  ① zip 압축 해제 위치 확인:
  > Glob C:\Users\<휘주님>\FILMN9\data\parsed_history\*.json

  파일 수가 2,526개 미만이면 휘주님께 압축 해제 요청.
  올바른 위치: data/parsed_history/ (루트 아래)

  ② DRY-RUN 시뮬레이션:
  > python db/load_history_to_mongo.py --dry-run

  파일 수 = 2,526 인지, 패턴 매칭 OK인지 확인.

  ③ 실제 업로드:
  > python db/load_history_to_mongo.py

  업로드 완료 후 출력:
    성공: 2526
    스킵: 0
    실패: 0
    MongoDB 현재 문서 수: 2,526건

  ④ 검증:
  > python db/load_history_to_mongo.py --list
  > python db/load_history_to_mongo.py --find 090430
  > python db/load_history_to_mongo.py --find 009150
  > python db/load_history_to_mongo.py --find 035420

  3종목 모두 정상 출력되면 적재 완료.


────────────────────────────────────────────────────────────────
STEP 6. 폴백 모드 (Mongo 끝까지 연결 불가 시)
────────────────────────────────────────────────────────────────

  핵심: FILMN9 백엔드는 Mongo 실패 시 자동으로
        data/parsed_history/*.json 파일을 직접 읽어 응답함.

  ① 압축 해제만 확인:
  > Glob data/parsed_history/*.json
  → 2,526개 파일이 있어야 함

  ② 백엔드 기동 (백그라운드):
  > python -m uvicorn backend.main:app --port 8000 --reload &

  ③ 폴백 작동 확인:
  > curl http://localhost:8000/api/overview/090430

  응답 JSON에서 "_source": "file" 이 보이면 폴백 모드 정상.
  ("mongo" 면 Atlas 모드)

  ④ 휘주님께 보고:
  "Atlas 연결 실패. 로컬 파일 폴백 모드로 정상 동작 중.
   2,526개 JSON 모두 응답 가능. 추후 Atlas 복구 시 STEP 5
   재실행으로 동기화 가능."
