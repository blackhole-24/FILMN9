================================================================================
  FILMN9 서버 수동 실행 가이드 (cmd 기준)  —  백엔드 + 프론트만 (AI 챗봇 제외)
  ※ 중요: 백엔드 포트는 8000 이 아니라 8090 입니다.
          (8000 은 Windows 예약 포트라 실행 안 됨. 프론트도 8090 보도록 설정돼 있음)
================================================================================

[ 켜는 순서 ]

 Step | 할 일                         | 명령어 / 액션
 -----+-------------------------------+-----------------------------------------------------------
  1   | 첫 cmd 창 열기                | 윈도우키 → cmd → Enter
  2   | FILMN9 폴더 이동              | cd C:\Users\Admin\FILMN9
  3   | 백엔드 실행                   | C:\Users\Admin\miniconda3\envs\FILMN9_env\python.exe -m uvicorn backend.main:app --reload --port 8090
  4   | 실행 확인                     | "Uvicorn running on http://127.0.0.1:8090" 보이면 성공 → 창 닫지 말기
  5   | 두 번째 cmd 창 열기           | 윈도우키 → cmd → Enter
  6   | 프론트 폴더 이동             | cd C:\Users\Admin\FILMN9\frontend
  7   | 프론트 실행                   | npm run dev
  8   | 실행 확인 (10~20초 대기)      | "Ready in xxxx ms" 보이면 성공 → 창 닫지 말기
  9   | 브라우저 접속                | http://localhost:3000
 -----+-------------------------------+-----------------------------------------------------------
 끌 때| 각 cmd 창에서                 | Ctrl + C  (또는 창 X 로 닫기)


[ 확인용 ]
  - 백엔드 단독 확인: 브라우저에서  http://localhost:8090/health
       → {"status":"ok", ...} 나오면 정상
  - 종목 화면 예시:  http://localhost:3000/stock/009150   (삼성전기)


[ 자주 나는 문제 ]
  - 3번에서 "[Errno 13] ... 8000 ..." 같은 오류가 보이면 → 포트가 8000 으로 돼 있는 것.
    반드시 --port 8090 인지 확인.
  - 7번에서 "npm: 명령을 찾을 수 없습니다" → Node.js 설치/PATH 문제. (Node 설치 확인)
  - 두 창은 서버가 켜져 있는 동안 계속 떠 있어야 함. 닫으면 서버 꺼짐.


[ 한 줄 요약 ]
  창1: cd C:\Users\Admin\FILMN9  →  ...python.exe -m uvicorn backend.main:app --reload --port 8090
  창2: cd C:\Users\Admin\FILMN9\frontend  →  npm run dev
  접속: http://localhost:3000
