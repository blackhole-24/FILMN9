## 1. 실험 목적

본 실험은 국내 주식 10개 종목에 대해 장 마감 후 1일 수익률을 계산하고, 해당 등락에 영향을 줬을 가능성이 있는 요인을 3가지로 요약하는 서비스 가능성을 검증하기 위해 진행했다.

주요 목표는 다음과 같다.

- 전일 종가 대비 당일 종가 기준 1D 수익률 산출
- 종목별 뉴스, 공시, 시장 지수, 비교 종목, 최근 가격 패턴을 결합
- LLM을 활용해 투자자가 이해하기 쉬운 3가지 요인으로 정리
- 무료 API 중심의 MVP 구성이 실제 서비스 설명에 충분한지 확인

## 2. 사용 데이터와 처리 흐름

사용 데이터는 다음과 같다.

| 구분 | 사용 데이터 | 역할 |
|---|---|---|
| 주가 | pykrx OHLCV | 전일 종가, 당일 종가, 거래량, 최근 5거래일 수익률 계산 |
| 시장 지수 | FinanceDataReader KOSPI/KOSDAQ | 종목 수익률이 시장 대비 강했는지 비교 |
| 뉴스 | 네이버 뉴스 검색 API | 당일 또는 직전 장 마감 이후 주요 이슈 수집 |
| 공시 | OpenDART | 당일/직전일 주요 공시 여부 확인 |
| LLM | OpenAI gpt-5.4-mini | 수집 근거를 바탕으로 3가지 요인 요약 |

처리 흐름은 다음과 같다.

1. 종목별 OHLCV 수집
2. 1D 수익률, 5D 수익률, 거래량 비율 계산
3. KOSPI/KOSDAQ 지수 수익률과 비교해 초과수익률 계산
4. 네이버 뉴스와 DART 공시 수집
5. 가격, 뉴스, 공시, 시장, 비교 종목 데이터를 하나의 evidence pack으로 구성
6. LLM이 evidence pack만을 근거로 3가지 요인과 주의 문구 생성

## 6. 결과 해석

이번 실험에서 가장 설명력이 높았던 종목은 삼성전기, 현대차, NAVER, 에코프로비엠이다. 이 종목들은 주가 움직임과 연결되는 뉴스 키워드가 비교적 명확했고, 시장 대비 초과수익률도 커서 LLM이 요인을 구조화하기 쉬웠다.

반대로 POSCO홀딩스, 경동나비엔, 파마리서치, 웹젠은 설명 가능하지만 확신도는 상대적으로 낮다. 특히 주가 변동폭이 작거나, 뉴스가 직접적인 주가 촉매라기보다 섹터 또는 일반 언급에 가까운 경우에는 "원인"보다는 "참고 요인"으로 표현하는 것이 적절하다.

따라서 서비스 화면에서는 모든 종목을 같은 톤으로 단정하기보다, 종목별로 근거 강도를 함께 보여주는 방식이 필요하다.

예시는 다음과 같다.

- 강한 근거: 목표주가 상향, 실적 전망, 직접 공시, 명확한 업종 이슈
- 중간 근거: 섹터 분위기, 비교 종목 동반 움직임, 최근 가격 추세
- 약한 근거: 단순 언급 기사, 낮은 거래량, 공시/수급 부재

## 7. 서비스 관점에서의 의미

이번 결과는 "무료 API 조합 + OpenAI API"만으로도 장 마감 후 종목별 수익률 설명 MVP를 만들 수 있음을 보여준다.

서비스 관점에서 유효했던 부분은 다음과 같다.

- 단순 수익률 표시가 아니라 "왜 움직였는지"를 함께 제공할 수 있다.
- 시장 대비 초과수익률을 같이 보여주면 상승/하락의 의미가 더 명확해진다.
- 최근 5거래일 패턴을 넣으면 하루 움직임을 과도하게 해석하는 문제를 줄일 수 있다.
- 비용이 낮아 10종목 이상의 반복 실행도 부담이 작다.

## 8. 현재 한계

현재 버전의 주요 한계는 다음과 같다.

1. 투자자별 수급 데이터가 아직 결과에 반영되지 않았다.
   - 모든 종목에서 수급 정보가 "없음"으로 표시됐다.
   - 기관, 외국인, 개인 순매수 데이터가 들어오면 설명력이 크게 좋아질 수 있다.

2. 뉴스 필터링이 일부 종목에서 약하다.
   - POSCO홀딩스처럼 기사 본문에만 종목명이 언급되는 경우가 포함됐다.
   - 발표/서비스용으로는 제목 또는 핵심 문장에 종목명이 직접 등장하는 뉴스를 우선해야 한다.

3. 하락 종목의 설명 방향성을 더 정교화할 필요가 있다.
   - 경동나비엔처럼 주가는 하락했지만 긍정 뉴스가 많이 잡히는 경우가 있다.
   - 이 경우 "긍정 뉴스에도 불구하고 왜 하락했는지"를 더 명확히 설명해야 한다.

4. 주가 영향 요인은 확정이 아니라 추정이다.
   - 뉴스, 공시, 가격 데이터 기반의 해석이므로 실제 원인을 단정하면 안 된다.
   - 서비스 문구에는 "영향을 줬을 가능성", "해석됩니다", "참고 요인" 같은 표현이 필요하다.

## 10. 발표용 핵심 메시지

발표에서는 다음 메시지로 정리할 수 있다.

> 저희 서비스는 장 마감 후 종목의 1일 수익률만 보여주는 것이 아니라, 뉴스, 공시, 시장 지수, 비교 종목, 최근 가격 패턴을 결합해 "왜 움직였는지"를 3가지 요인으로 요약합니다.

> 10개 종목 실험 결과, 전 종목에 대해 결과 생성에 성공했고, 특히 삼성전기처럼 명확한 뉴스와 강한 가격 움직임이 있는 종목에서는 설명력이 높게 나타났습니다.

> 비용 측면에서도 10종목 전체 분석에 약 80원 수준이 소요되어, MVP 단계에서는 무료 데이터 API와 OpenAI API 조합만으로도 충분히 실험 가능하다는 점을 확인했습니다.

## 11. 결론

이번 10종목 실험은 서비스 방향성이 타당하다는 것을 보여준다.

특히 장 마감 후 리포트 방식은 실시간 시세 API나 WebSocket 없이도 구현 가능하며, 무료 데이터 소스와 LLM을 조합해 사용자가 이해하기 쉬운 요약 결과를 제공할 수 있다.

다만 모든 종목에서 원인이 명확하게 나오는 것은 아니므로, 최종 서비스에서는 "요인 3개"와 함께 근거 강도, 데이터 부족 여부, 수급/공시 부재를 명확히 표시하는 것이 중요하다.
