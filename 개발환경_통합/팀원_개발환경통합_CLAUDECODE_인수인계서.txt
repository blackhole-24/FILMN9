STEP 0. 사전 점검
================================================================

  Bash 도구로 차례대로 실행하고 결과 확인:

  > python --version       # Python 3.10+ 필요
  > node --version          # v20+ 필요
  > npm --version           # 10+ 권장
  > git --version           # 2.30+ 권장

  하나라도 없거나 버전 미달이면 사용자에게 설치 요청:
    - Python: https://www.python.org/downloads/
    - Node.js: https://nodejs.org/ (LTS 20+)
    - Git: https://git-scm.com/downloads

STEP 1. GitHub 레포 클론
================================================================

  ① 작업 디렉터리 결정 (사용자에게 확인 후 결정)
    - Windows 권장: C:\Users\<본인>\FILMN9
    - Mac/Linux 권장: ~/projects/FILMN9

  ② 클론 실행:
  > cd <상위 디렉터리>
  > git clone https://github.com/<ORG>/FILMN9.git
  > cd FILMN9

  ③ 클론 확인:
  > ls 개발환경_통합/
  (또는 dir 개발환경_통합\ on Windows)

  파일들이 보여야 함:
    - SETUP.md
    - setup.bat (Windows) / setup.sh (Mac/Linux)
    - .env.template
    - requirements.txt
    - 폴더구조_가이드.md
    - 기타 가이드 문서


================================================================
STEP 2. 개발환경_통합/ 폴더 진입 및 setup 자동화
================================================================

  ① 사용자에게 SETUP.md 내용 확인 권장:
  > Read C:\Users\<본인>\FILMN9\개발환경_통합\SETUP.md

  ② 자동 setup 스크립트 실행:
    Windows:
    > 개발환경_통합\setup.bat

    Mac/Linux:
    > bash 개발환경_통합/setup.sh

  ③ setup 스크립트가 실패하면 STEP 3~6을 수동 진행.


================================================================
STEP 3. .env 파일 생성 (사용자 입력 필수)
================================================================

  ⚠️ 보안상 .env는 GitHub에 커밋되지 않음.
     사용자가 직접 API 키를 입력해야 함.

  ① 템플릿 복사:
  Windows:
  > copy 개발환경_통합\.env.template .env

  Mac/Linux:
  > cp 개발환경_통합/.env.template .env

  ② 사용자에게 .env 파일 열어서 다음 키 입력 요청:
    - DART_API_KEY        (https://opendart.fss.or.kr/ 발급)
    - OPENAI_API_KEY      (https://platform.openai.com/api-keys)
    - MONGO_URI           (팀 리더에게 받은 Atlas URI)
    - MONGO_DB=filmn9
    - MONGO_COLLECTION=histories

  ③ 입력 확인:
  > Grep "MONGO_URI" .env       # 값이 채워졌는지 확인

  ※ 빈 값으로 두어도 진행 가능 (폴백 모드 동작),
    단 데이터 수집/LLM 기능은 제한됨.


================================================================
STEP 4. Python 가상환경 + 의존성 설치
================================================================

  ① 가상환경 생성:
  > python -m venv venv

  ② 활성화:
    Windows:
    > venv\Scripts\activate
    Mac/Linux:
    > source venv/bin/activate

  ③ 의존성 설치:
  > pip install --upgrade pip
  > pip install -r requirements.txt

  ④ 핵심 패키지 확인:
  > pip show fastapi pymongo openai pandas

  설치 실패 시 사용자에게 에러 메시지 그대로 보고.


================================================================
STEP 5. Frontend 의존성 설치
================================================================

  ① frontend-next/ 폴더 진입:
  > cd frontend-next

  ② npm install:
  > npm install

  설치 시간: 약 2-5분 (인터넷 속도 의존)

  ③ 설치 확인:
  > Glob frontend-next/node_modules/.bin/next
  (파일 존재하면 OK)

  ④ 루트로 복귀:
  > cd ..

STEP 6. SQLite DB 초기화 + 데모 데이터 적재
================================================================

  ① DB 파일이 이미 있는지 확인:
  > ls data/filmn9.db
  (또는 dir data\filmn9.db on Windows)

  ② GitHub 레포에 filmn9.db 가 포함되어 있다면 → STEP 6 건너뜀.

  ③ 없으면 초기화 + 적재:
  > python db/init_db.py
  > python db/batch_demo3.py

  ④ 검증:
  > python check_full_schema.py

  출력에 9개 테이블 모두 보여야 함:
    - company_info
    - financials
    - financial_detail
    - ohlcv
    - shareholders
    - executives
    - disclosures
    - credit_ratings
    - valuations


================================================================
STEP 7. MongoDB 연결 시도 (실패 시 폴백)
================================================================

  ① 연결 테스트:
  > python db/test_mongo.py

  ② 분기 처리:

  성공 → STEP 8로 진행

  실패 (TLSV1_ALERT 등) → 폴백 모드 활성화:
    ① data/parsed_history/ 폴더 확인:
       > Glob data/parsed_history/*.json
       (최소 3개 — 090430, 009150, 035420 — 있어야 함)

    ② 파일 없으면 사용자에게 briefs_final.zip 또는
       parsed_history 폴더 공유 요청.

    ③ 폴백 모드는 자동 동작하므로 별도 설정 불필요.

STEP 8. 백엔드 + 프런트엔드 동시 기동
================================================================

  ① Windows 사용자:
  > start.bat

  Mac/Linux 사용자:
  > bash start.sh
  (없으면 별도 터미널 2개에서 각각:)

[자주 발생하는 문제 & 해결]
================================================================

Q1. "ModuleNotFoundError: No module named 'fastapi'"
    A. venv 활성화 안 됨. STEP 4-② 다시 수행.

Q2. "npm ERR! ENOENT package.json"
    A. frontend-next/ 폴더에 있는지 확인. cd frontend-next 필수.

Q3. "filmn9.db: no such table"
    A. STEP 6 다시 수행. init_db.py → batch_demo3.py 순서.

Q4. MongoDB TLSV1_ALERT 에러
    A. 폴백 모드로 진행. STEP 7 분기 처리 참조.
       자세한 해결은 휘주님_MongoDB_환경구축_가이드.md 참조.

Q5. 포트 충돌 (3000 or 8000 already in use)
    A. Windows: netstat -ano | findstr ":3000"
       찾은 PID 종료: taskkill /PID <pid> /F
       Mac/Linux: lsof -i :3000 → kill -9 <pid>

Q6. CORS 에러 (브라우저 콘솔)
    A. api/main.py 의 CORS 설정 확인.
       localhost:3000 이 allow_origins 에 포함되어야 함.

Q7. 한글 깨짐 (Windows PowerShell)
    A. chcp 65001 실행 → UTF-8 모드 전환.
       또는 git config --global core.quotepath false
