## 1. 피어 베타 산출 (Phase 2-A)

**모듈:** `peer_beta/`

1. T일 (기본 `date.today()`) 기준으로 2년치 매주 금요일 후보 생성
   (금요일 비영업일 → 직전 영업일 대체)
2. KRX OpenAPI에서 4사 종가 + 시장지수 일별 데이터 수집 (캐시 우선)
3. 일자별 캐시 → 주간 종가 패널 → 주간 수익률 계산
4. OLS 회귀 (`r_stock = α + β · r_index + ε`)
5. **Winsorize ±3σ** 이상치 처리 (디폴트, 표본 N 보존)
6. **Blume 조정** β_adj = (2/3)·β_raw + (1/3)
7. 검증: R² ≥ 0.10, |z| ≤ 4.0, missing weeks = 0

**산출:** `peer_beta/results/peer_beta_<T>.json`

## 4. WACC 산출 (Phase 3)

**모듈:** `valuation_engine/wacc_engine.py`

### 4.1 입력
- 피어 베타 결과 (`run_beta()`)
- XBRL 결과 (`load_xbrl()`)
- 시가총액 (`load_equity()`)

### 4.2 피어별 Hamada Unlever (3사, 타겟 제외)
```
β_U,i = β_L_adj,i / [1 + (1 − t_i) × (D_i / E_i)]
```

### 4.3 피어 집계 — 중위값
- β_U_median
- D/E_median (= 타겟 목표자본구조)

### 4.4 타겟 Hamada Relever
```
β_L,target = β_U_median × [1 + (1 − t_target) × DE_median]
```

### 4.5 Rf — ECOS 실시간 호출
- `fetch_rf(eval_d)` → 국고채 10년 SPOT

### 4.6 SRP — 타겟 시총 자동 매칭
- `match_srp(target_E)` → 3분위 중 자동 선택

### 4.7 Ke
```
Ke = Rf + β_L,target × ERP + SRP + CRP
```

### 4.8 Kd — 사업보고서 RAG + KOFIA 매핑
1. RAG로 회사채 + CP 신용등급 동시 추출 (가장 최근 평가일)
2. 우선순위:
   - 회사채 등급 있음 → `kd_loader.get_kd_by_rating()` 직접 조회
   - CP 등급만 있음 → `cp_to_bond_converter.convert_cp_to_bond_5y()` 변환:
     ```
     Kd = CP1년 + (KOFIA 회사채5년 매핑등급 − KOFIA CP1년 원등급)
     ```
   - 둘 다 없음 → RuntimeError
3. 매핑 등급별 yield 데이터:
   - `채권시가평가기준수익률.csv` (회사채 I 공모사채 무보증 5년)
   - `cp_수익률.csv` (CP 5사 평균 1년)

### 4.9 세후 Kd
```
Kd_after_tax = Kd × (1 − t_target)
```

### 4.10 WACC
```
WACC = (E_w × Ke) + (D_w × Kd_after_tax)
   E_w = 1 / (1 + DE_median)
   D_w = DE_median / (1 + DE_median)
```

산출: `data/wacc/wacc_result_<T>.json`

## 5. DCF 산출 (Phase 4)

**모듈:** `valuation_engine/dcf_engine.py`

### 5.1 과거 3년 정상화 비율 (평균)
- OPM, D&A율, CapEx율, NWC율
- 각 항목 ±50% 이격 시 경고

### 5.2 5년 명시예측 + Terminal Value
- 매출 성장률 Fade-out (Y1=CAGR, Y2=×0.8, Y3/Y4=×0.7, Y5=g=2.0%)
- 각 연도:
  ```
  Revenue_t = Revenue_{t-1} × (1 + g_t)
  EBIT_t    = Revenue_t × OPM
  t_rate_t  = get_marginal_tax_rate(EBIT_t)   ← 매년 갱신
  D&A_t     = Revenue_t × DA_ratio
  CapEx_t   = Revenue_t × CAPEX_ratio
  ΔNWC_t    = (Revenue_t × NWC_ratio) − NWC_{t-1}
  FCFF_t    = EBIT_t × (1 − t_rate_t) + D&A_t − CapEx_t − ΔNWC_t
  PV_t      = FCFF_t / (1 + WACC)^t
  ```
- Y+5 CapEx > D&A → D&A로 강제 조정

### 5.3 Gordon Growth Terminal Value
```
FCFF_6 = FCFF_5 × (1 + g)
TV     = FCFF_6 / (WACC − g)
PV(TV) = TV / (1 + WACC)^5
EV     = ΣPV(FCFF_t) + PV(TV)
```

### 5.4 위계 검증
- `g < Rf < WACC` (위반 시 경고만, 중단 안 함)

산출: `data/dcf/dcf_result_<T>.json`

## 6. Equity Value & 주당가치 (Phase 5)

**모듈:** `valuation_engine/equity_value.py`

```
Equity Value = EV − Net Debt + NOA_clean − 비지배지분
   Net Debt  = IBD − Cash
   NOA_clean = NOA (현금 이중차감 방지)
주당가치     = Equity Value / 보통주 유통주식수
```
