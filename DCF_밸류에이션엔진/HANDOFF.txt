【2. 핵심 설계 결정사항】
─────────────────────────────────────────────────────────────────────────────

(사용자가 confirmed 한 모든 결정 — 변경 시 사용자와 협의)

DCF 모델:
  - Forward DCF (v3 표준) — FCFF 5년 명시예측 + Gordon Growth TV
  - 5년 정상화 (FY2021~2025)
  - FCFF Y+1 < 0 또는 EV < 0 → DCF 가치 숨김, 멀티플만 표시
  - g_perpetual = 2.0% (한국 장기 GDP 성장률 기준)
  - Fade-out 비율 = 3년 CAGR × 0.8 × 0.7 (Damodaran 표준)

WACC:
  - WACC = E/V·Re + D/V·Kd(1−τ) 표준 산식
  - βU 산출: Hamada Unlever — βU = βL / [1 + (1−t)·D/E]
  - βL 산출: Hamada Relever — βL_target = βU_median × [1 + (1−t)·D/E_median]
  - β 회귀: 주간 2년치 OLS, Winsorize ±3σ, Blume α=2/3 조정
  - Rf: 10년 국고채 (ECOS API, 일자별 캐시)
  - ERP: 8% (Base, 신뢰구간 7~9%) — 한공회 가이던스
  - SRP: 한공회 표 (Mid -0.36% 등)
  - CRP: 0% (한국 POC 정책)
  - Kd: KOFIA 무보증 5년 회사채 + 신용등급별
  - 한계세율: 한국 법인세 누진 (200억/20조/3000억 구간)
  - WACC 신뢰구간: Fernandez (IESE 2019) RSS 결합
    └ Δ_total = √(Δ_βU² + Δ_ERP²)  (독립 변수 분산 결합)

Equity Value (방법 1):
  - Equity Value = EV − Net Debt + NOA_clean − NCI(비지배지분)
  - Cash 이중차감 방지:
        Net Debt    = IBD − Cash       (현금성자산 차감)
        NOA_clean   = NOA_raw − Cash   (현금성자산 중복 제외)
  - NCI: XBRL `ifrs-full:NoncontrollingInterests` 직접 추출 (None=실패, 0=정상)
  - Damodaran 표준: 연결 FCFF 기반 EV → 모회사 보통주 주주 청구권만

멀티플 4종:
  - EV/EBITDA, EV/Sales: 표준
  - PER 분모: XBRL `BasicEarningsLossPerShare` 직접 보고값 사용 (가중평균 유통주식 자동 반영)
  - PBR 분모: (지배지분 자본 − 우선주 자본금) / 보통주 유통주식수
  - 이격 경고: P25 미만 / P75 초과 → dict 리스트 (multiple/target/median/p25/p75/zone)

자동 피어 산정 6차원 가중치:
  sector_sim   0.30  (WICS 소섹터 + 사업보고서 RAG 임베딩 보강)
  biz_tag      0.15  (BIZ_TAG 사업모델 일치)
  mktcap_sim   0.20  (시총 log scale)
  revenue_sim  0.15  (매출 log scale)
  leverage_sim 0.10  (D/E 차이)
  cycle_sim    0.10  (산업 OPM z-score)

피어 자격 (_is_eligible):
  - 상장 < 2년 → 제외 (β 회귀 불가)
  - NOPAT 5년 중위값 ≤ 0 → 제외 (가치평가 부적합)
  - XBRL 3년 미만 → 제외
  - PARTIAL 모드 (KRX 시총만): NOPAT 검증 우회 + 점수 × 0.7

신용등급 추출 (가장 최근 등급 선택):
  - 청크 검색: chroma 의미검색 우선 (top_k=25) → 실패 시 jsonl 키워드 fallback
  - LLM (GPT-4o-mini): 모든 등급 이력 + 평가일 빠짐없이 추출만
  - Python `_pick_latest()`: 날짜 내림차순 정렬 → 첫 행 = 가장 최근
  - 회사채(장기) 우선 → 없으면 CP(단기) → 회사채 변환
  - "AA" → "AA0" 자동 정규화 (normalize_rating)

【7. Phase 별 산출물】
─────────────────────────────────────────────────────────────────────────────

Phase 1-A. peer_beta — peer_beta/results/peer_beta_<date>.json
  - 피어별 β_raw, β_adj (Blume), R², winsorize 통계

Phase 1-B. XBRL 재무 — data/xbrl/<corp>_<year>.json (회사·연도별)
  - 재무: 매출, EBIT, D&A, CapEx, NWC, IBD, NOA, NOPAT
  - 자본: equity_total, equity_parent, minority_interest, preferred_capital
  - EPS: basic_eps (XBRL 직접 보고)

Phase 2-A. 시가총액 E — data/equity/peers_equity_<ticker>_<date>.json
  - 회사별 close_price, common_issued/treasury/float, E_market_cap

Phase 3. WACC — data/wacc/wacc_result_<date>.json
  - rf, ERP, SRP, CRP, βL_target, Ke, Kd, Kd_after_tax, We/Wd, WACC
  - 신뢰구간: WACC_low/high (Fernandez RSS 결합)
  - 메타: WACC_bu_low/high (βU 변동), WACC_erp_low/high (ERP 변동)
  - 신용등급: rating, rating_type (bond/cp_mapped), 평가사, 평가일
  - 산업 사이클: OPM z-score, 5년 추이

Phase 4. DCF — data/dcf/dcf_result_<date>.json
  - FCFF 5년 + TV (PV 분해)
  - implied_roic, invested_capital, eva_spread
  - dcf_valid, dcf_confidence (high/medium/low/very_low)
  - dcf_max_opm_deviation (OPM 이격율)

Phase 5. Equity Value — equity_value 결과 (run_valuation 통합)
  - IBD, cash, net_debt, noa_raw, noa_clean, minority_interest
  - EV, equity_value, common_float, fair_price, current_price, upside_pct
  - dcf_valid flag 전파

Phase 6. 멀티플 — multiples 결과
  - 피어 P25/Median/P75 (EV/EBITDA, EV/Sales, PER, PBR)
  - 타깃 멀티플 + 역산가
  - dispersion_warnings (dict 리스트)

Phase 7. 시나리오 — uncertainty 결과
  - Bear/Base/Bull (price, EV, upside_pct, EV/EBITDA)
  - WACC × g 민감도 매트릭스 (3×3)
  - 토네이도 (매출/OPM/CapEx/NWC/WACC/g 변동)

최종 통합 — results/valuation_<ticker>_<date>.json
  - Streamlit Tab 2 가 직접 로드하는 단일 JSON

증상: '청크 파일 비어있음'
  → KOSPI/ 또는 KOSDAQ/ 에 해당 종목 청크 jsonl 없음
  → 사전 임베딩된 chroma_db 활용 (자동 폴백)
  → 그래도 실패하면 사업보고서 PDF 수동 분할 + 임베딩 필요

증상: 'OpenAI API 키 없음'
  → .env 에 OPENAI_API_KEY 추가
  → 실데이터 정책상 RAG 우회 안 됨

증상: '신용등급 RAG 실패'
  → 청크 내 신용등급 정보 부재 또는 GPT 추출 실패
  → fetch_credit_rating.py 로그 확인 — 어느 분기에서 실패했는지

증상: 'DCF 신뢰도 매우 낮음' 빨간 박스
  → OPM 이격이 매우 큼 (예: ±500%+)
  → 적자/흑자 전환 회사. DCF 결과보다 멀티플 참고

증상: Tab 2 에 옛 종목 결과 표시
  → session_state.valuation_data stale
  → "평가 실행" 시 자동 초기화되어야 정상
