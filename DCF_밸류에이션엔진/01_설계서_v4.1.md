  - 2억~200억: 22.0%

  - 3,000억 초과: 27.5%
- WACC: 타겟·피어 각자의 최근 EBIT 기준
- DCF: 매년 예측 EBIT 기준 자동 재산정

### §1.6 Levered Beta
- KRX OpenAPI 주간(금요일) 종가, 2년 lookback (104주)
- 시장: KOSPI/KOSDAQ 자동 매칭
- OLS 회귀: r_stock = α + β · r_index + ε
- **Blume 조정: β_adj = (2/3)·β_raw + (1/3)·1.0** (정확분수, KRX 공시와 정합)
- **이상치 처리: Winsorize ±3σ** (디폴트, 표본 N 보존)
- 검증: R² ≥ 0.10, |z| ≤ 4.0, missing weeks = 0

### §1.7 Hamada Unlever (피어별)
```
β_U,i = β_L_adj,i / [1 + (1 − t_i) × (D_i / E_i)]
```
- D_i = 팀원 XBRL `ibd` (단기차입금·장기차입금·사채·리스부채 합산)
- E_i = T일 보통주 종가 × (보통주 발행 − 자기주식)
- t_i = 피어 i의 최근 EBIT 기준 한계세율

### §1.8 피어 집계 — 중위값 (Median)
- β_U 중위값 (타겟 제외, 피어 3사)
- D/E 중위값 (타겟 제외, 피어 3사)

### §1.9 타겟 Hamada Relever
```
β_L,target = β_U,med × [1 + (1 − t_target) × (D/E)_med]
```

### §1.10 자기자본비용 Ke
```
Ke = Rf + β_L,target × ERP + SRP + CRP
```

### §1.11 타인자본비용 Kd — 동적 산정
**산출 경로 (우선순위):**
1. 사업보고서 RAG (ChatGPT 4o-mini)로 회사채 + CP 신용등급 동시 추출
2. 회사채 등급 있음 → KOFIA 회사채 I(공모사채) 무보증 5년 매핑 등급 yield
3. CP 등급만 있음 → **Term-Credit Spread 분해 변환**:
   ```
   Kd = CP1년 yield + (KOFIA 회사채5년 매핑등급 − KOFIA CP1년 원등급)
   ```
4. 둘 다 없음 → RuntimeError (임의값 금지)

**CP → 회사채 신용등급 매핑 (한국 3대 신평사 표준):**
| CP | 회사채 매핑 |
|---|---|
| A1 | AA- |
| A2+ | A+ |
| A2 | A0 |
| A2- | A- |
| A3+ | BBB+ |
| A3 | BBB0 |
| A3- | BBB- |
| B+~D | BBB- (보수적 폴백) |

**데이터 소스:**
- 회사채 5년 yield: `VAR/채권시가평가기준수익률[_YYYYMMDD].csv` (KOFIA 평가사 평균)
- CP yield: `VAR/cp_수익률[_YYYYMMDD].csv` (KOFIA 5사 평균, 1년 만기)

**세후 Kd:**
```
Kd_after_tax = Kd × (1 − t_target)
```

### §1.12 WACC
```
WACC = (E / (D+E)) × Ke + (D / (D+E)) × Kd_after_tax
```
- 가중치 = 타겟 목표자본구조 = 피어 D/E 중위값

## §2. DCF 산출

### §2.1 정상화 비율 (모두 3년 평균)
- OPM = EBIT / Revenue
- D&A율 = D&A / Revenue
- CapEx율 = CapEx / Revenue (팀원 코드: 유형자산 Gross)
- NWC율 = NWC / Revenue
- 3년 중 ±50% 이격 시 경고

### §2.2 매출 성장률 Fade-out
| 연도 | 성장률 |
|---|---|
| Y+1 | 3년 CAGR |
| Y+2 | Y+1 × 0.8 |
| Y+3 | Y+2 × 0.7 |
| Y+4 | Y+3 × 0.7 |
| Y+5 | g_perpetual = 2.0% |

### §2.3 연도별 세율 — 매년 예측 EBIT 기준 갱신
```
for t = 1..5:
    EBIT_t = Revenue_t × OPM
    t_rate_t = get_marginal_tax_rate(EBIT_t)   ← 매년 재산정
    FCFF_t   = EBIT_t × (1 − t_rate_t) + D&A_t − CapEx_t − ΔNWC_t
```
**과거 v4 차이:** 이전엔 최근 실적 EBIT 1회 산정 → 5년 고정. v4.1은 매년 갱신.

### §2.4 Terminal Value
```
FCFF_6 = FCFF_5 × (1 + g_perpetual)
TV     = FCFF_6 / (WACC − g_perpetual)
PV(TV) = TV / (1 + WACC)^5
EV     = ΣPV(FCFF_t) + PV(TV)
```

### §2.5 위계 검증
```
g_perpetual < Rf < WACC   (필수)
```
위반 시 warning 출력.

### §2.6 Y+5 CapEx 정상화
- CapEx_5 > D&A_5 → CapEx_5 = D&A_5 강제 조정 (영구성장에서 CapEx > 감가상각은 비현실적)

### §2.7 EV → Equity Value → 주당가치
```
Equity Value = EV − Net Debt + NOA_clean − 비지배지분
주당가치     = Equity Value / 보통주 유통주식수
```

**결정사항 #1: 현금성자산 처리**
- Net Debt 산정에서만 차감: `Net Debt = IBD − Cash`
- NOA에서는 제외 (이중차감 방지)

**결정사항 #5: NOA 분류**
- 팀원 `NOA_RULES_FINAL_V3` 그대로 사용 (확실/기본/조건부/OA/별도처리 5분류)

## §3. 불확실성 표현 (필수 출력 3종)

### §3.1 시나리오 — Bear / Base / Bull
- 변동 변수: 매출 성장률 Y+1, OPM, CapEx율, NWC율
- 각 변수의 과거 3년 시계열에서 (최저 / 평균 / 최고) 추출
- Bear: 성장↓·OPM↓·CapEx↑·NWC↑ 조합
- Bull: 반대
- 다른 변수 (WACC, g, D&A율, 세율)는 Base 고정

### §3.2 민감도 매트릭스
- 축: WACC ±1%p × g ±0.5%p
- 출력: 3×3 주당가치 매트릭스

### §3.3 토네이도 — 변수별 ± 변동 영향도
| 변수 | ± 범위 |
|---|---|
| 매출 성장률 Y+1 | ±2%p |
| OPM | ±2%p |
| CapEx율 | ±2%p |
| NWC율 | ±2%p |
| WACC | ±1%p |

## §6. 일반투자자 친화 설계 원칙

1. **임의값 절대 금지** — 데이터 부재 시 RuntimeError, "정확값"으로 표시 안 함
2. **자동 갱신 가능 항목은 모두 자동** — Rf, 종가, 시총, SRP 모두 실시간 호출
3. **이상치 처리는 표본 보존 우선** — Winsorize ±3σ (drop 아님, 일반투자자에게 "N이 줄었다"보다 "특이 사건 영향을 ±3σ로 제한했다" 가 설명·이해 친화)
4. **위계 검증·이격 경고는 항상 출력** — g < Rf < WACC, 멀티플 백분위 이격, Implied ROIC vs WACC
