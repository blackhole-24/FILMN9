1. 재무 단위 통일
   - financial_detail은 종목마다 단위 혼재 (원/천원/백만원)
   - financials 테이블은 DART API 직접 재적재 → 전체 /1e6 백만원 통일
   - 재무표 화면 표시 시 per-stock 단위 자동감지 (_detect_fd_unit)

2. 주가 suffix (.KS/.KQ)
   - yfinance는 KOSPI=.KS, KOSDAQ=.KQ 구분 필수
   - ticker_suffix 테이블에 2,877개 종목 매핑
   - 실시간 가격이 50% 이상 괴리 시 반대 suffix 자동 fallback

3. 거래정지 판단 로직 (우선순위)
   - 1순위: KIND 공식 (kind.krx.co.kr) — 로그인 불필요 AJAX API
   - 2순위: 추정 하이브리드 (주가 0, 유의종목, 관리종목)
   - 3순위: DART 공시에서 거래정지 공시 보완

4. 고객사 표기
   - B2B (기업 고객), B2C (개인/소비자 고객), MIXED (둘 다)
   - 자기 자신/자회사 제외 (_core 함수)
   - 표현 빈도 높은 순으로 채널 표기 (수출/내수/온라인 등)

5. Sankey 손익흐름도
   - 색상: 매출=파랑(#3b82f6), 이익=초록(#22c55e), 비용=빨강(#ef4444)
   - 음수 노드: 노란색(#eab308) — 적자 구간 강조
   - 적자 기업도 모든 노드 표시: abs()+floor 폭으로 최소 띠 보장
   - 연결 재무제표 우선, 없으면 별도 재무

6. 신용등급
   - NICE/한기평/KIS 모두 유료 API → 무료 커버리지 없음
   - credit_ratings 테이블 없음 (Mock 데모 3개만 처리, 현재 화면에서 제거됨)
