## 1. WBS 슬라이드 (PPT 4페이지 '개발 과정') — 글씨 대폭 축소 ★
- 지금도 글씨가 너무 많음. **핵심 제목만** 남기고, **각 칸이 줄바뀜 없이 한 줄**에 들어오게 요약.
- 예: "기획서 · 요구사항정의서 · 협업환경 구축" → **"기획 · 요구사항"** 수준으로 더 짧게.
- 담당 파트 칸도 "기업분석 / 밸류에이션" 정도로 짧게. 표 전체가 한눈에 읽히도록.
- 폰트 키우고(11→12.5pt+), 행 높이 여유. 길어서 줄바뀌는 셀이 0이 목표.

## 2. 팀 구성 슬라이드 (PPT 5페이지) — 4명 + Fade-out 애니메이션 ★
- 현재 **3박스(이형주·고휘주·유태상)** → **4박스로**: **손소희** 박스 추가 (밸류에이션 파트, 중도 합류 종료).
  - 박스 내용: 손소희 = "밸류에이션 파트 (초기 합류)".
- **애니메이션(슬라이드쇼 클릭 순서)**:
  1. 슬라이드 진입 → **4명 모두 표시**
  2. **클릭 1회 → 고휘주·손소희 박스가 Fade Out** (사라짐) → 이형주·유태상 2명만 남음 (＝ "처음 4명으로 시작, 현재 2명" 서사)
  3. **클릭 2회 → 다음 슬라이드로 전환**
  - PowerPoint: 두 박스에 [나타내기 애니메이션 ❌ → 끝내기 '페이드'] 적용, 시작=클릭할 때, 두 박스 동시(이전 효과와 함께).
- 제목은 '세 명의 기여자' 같은 표현 말고 **"팀 구성 · 역할 분담"** 유지(유치한 제목 금지).
