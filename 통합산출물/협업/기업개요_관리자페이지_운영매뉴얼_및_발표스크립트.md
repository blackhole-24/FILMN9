## 2. 기업개요 검증 탭 (🔍 verify)
부제 "NO-MOCK · 화면에 쓰는 DB 값이 논리적으로 맞는지 직접 검사". 버튼을 눌러 실측.

### ① 내부 정합성 검증 (DB 값 자체 검사)
- **검증 파트(드롭다운 4종)**:
  - **재무 항등식** — 「자산총계 = 부채총계 + 자본총계」 성립(±0.5%). 불일치=재무 파싱 오류 의심.
  - **주가 OHLC 유효성** — low ≤ open·close ≤ high, high ≥ low, volume ≥ 0.
  - **기업개요 완전성** — 핵심필드(corp_name·market·sector) 결측 여부.
  - **밸류 정합성** — 화면 상승여력 `upside_pct` = (적정가−현재가)/현재가×100 일치(±1%p).
- **[샘플 검증]**(무작위 N개 1~50, 즉시) / **[전수 검증]**(전 종목 배치).
- 결과: **검사 · 통과 · 불일치 · 오류율(%)** + 불일치 표(종목·항목·DB값·기대값). **0%면 NO-MOCK 일치.**

### ② DART 원문 대조 (요약 재무 ↔ XBRL 상세)
- 화면용 요약 재무(`financials`)가 DART 사업보고서 XBRL 상세(`financial_detail`)와 일치하는지 대조.
- 항목: 자산·부채·자본총계 + 매출·영업이익·당기순이익(연결 우선). 단위(백만원↔원) 자동 보정, ±1% 이내면 일치.
- **[원문 대조(샘플 40)] / [전수 대조]** → 대조·일치·불일치·일치율 + 항목별 통계. 불일치=파싱/집계 오류 의심.

### ③④⑤ 산출물 검증 (자동 로드)
- **③ 히스토리브리핑 검증** — 브리핑 산출물 존재·품질 점검(/api/admin/verify/briefing).
- **④ 챗봇 검증** — RAG 챗봇 서버 가용·응답 점검(/api/admin/verify/chatbot). (GPU 정지 시 'server_up=false'가 정상)
- **⑤ 계열사 검증** — 계열사 시각화 산출물 점검(/api/admin/verify/affiliate).

**점검 주기**: 배치 직후 = ① 전수 + ② 전수(새 데이터 깨짐 가장 먼저 발견) / 주간 = 샘플 / 공시 시즌 = 재무 갱신 후 ①② 재실행.

## 3. 트러블슈팅 & 용어
| 증상 | 조치 |

## 4. ★발표 시연 스크립트 (운영 2분 + 검증 2분)

### 운영 탭 — (약 2분)
"기업개요 운영 탭은 **'각 기능이 어떤 공식 데이터에서 출발해 화면까지 어떻게 흐르고, 지금 정상인지'**를 한눈에 보는 콘솔입니다.
① **기능 모듈 현황** — 기업개요·재무·Sankey·계열사·밸류·챗봇이 각각 DART·KRX 같은 원천에서 화면까지 흐르는 경로와 작동 상태를 보여줍니다.
② **커버리지·DB 현황** — 전 종목 대비 데이터 보유율과 16개 테이블 행수입니다. **비어 있으면 가짜로 채우지 않고 빨강으로 정직하게** 둡니다 — 저희 NO-MOCK 원칙입니다.
③ **데이터 신선도·스모크 테스트** — 주가는 매 거래일 16시 자동 갱신되고, 샘플 종목이 종목상세에 필요한 데이터를 다 갖췄는지 즉석 점검합니다.
④ 챗봇·AWS 비용까지 한 화면에서 운영 상태를 확인합니다. 즉 **이 모든 수치는 누르는 순간 실제 DB를 조회한 실측값**입니다."

### 검증 탭 — (약 2분)
"검증 탭은 **'화면에 보이는 숫자가 진짜 맞는지'를 말이 아니라 버튼으로 증명**합니다.
① **내부 정합성** — 예를 들어 재무 파트를 골라 검증을 누르면, 전 종목의 「자산 = 부채 + 자본」 회계 항등식이 맞는지, 주가의 고저가 논리가 맞는지를 검사해 **오류율을 0%로** 보여줍니다.
② **DART 원문 대조** — 저희 요약 재무가 DART 사업보고서 원문(XBRL)과 일치하는지 직접 대조해 일치율을 띄웁니다 — **누구나 원본으로 팩트체크할 수 있게** 한 겁니다.
③ 히스토리 브리핑·챗봇·계열사 산출물까지 검증합니다. 한마디로 **'실데이터만, 항상 원본과 대조 가능하게, 틀리면 숨기지 않고 드러낸다'** 입니다."
