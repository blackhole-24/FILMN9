# FINSIGHT 라이브 시연 스크립트 (발표용)

> 실제 서비스 접속 시연. 동선 = 메인 → 기업개요 → 밸류에이션 → AI 챗봇 → 관리자. 약 5~7분.
> 관통 서사 = '김초심'의 5가지 질문: ① 뭐 하는 회사? ② 돈은 잘 벎? ③ 비싼가 싼가? ④ 궁금한 건? ⑤ 스스로 판단.
> 라이브: https://43.203.94.124.nip.io · 작성 2026-06-19 창A
> ★데모 종목: **삼성전기(009150)** 권장(영업이익·계열사·밸류·튜토리얼·챗봇 전부 충실). 발표 전 밸류 탭 데이터 있는지 1회 확인.

## 0. 시연 준비 (발표 10분 전)
- 챗봇 GPU start → 워밍업 ~6분 → AI 챗봇 탭 'up' 확인(창A).
- 브라우저 탭 미리 열기: 메인 / 종목상세 / `/admin`(로그인까지).
- 새로고침 1회(최신 시세·캐시 워밍).

## 1. 메인페이지 — "어디서 시작하지?" (①로 진입)
- 🖱️ 통합 스마트검색에 **"삼성전기"**(또는 종목코드/업종) 입력 → 첫 결과 클릭.
- 🎙 "막막한 일반 투자자가 회사명·업종·종목코드 아무거나 넣으면 바로 찾습니다. 추천 종목·업종 둘러보기·관심종목도 한 화면에요. 한 종목을 고르면 — 궁금증을 **묻는 순서대로** 답이 나옵니다."

## 2. 기업개요 탭 — "① 뭐 하는 회사? ② 돈은 잘 벎?"
- 🖱️ **히스토리 브리핑** — 회사 연혁·사업 요약(AI 생성, 신뢰도 등급).
- 🎙 "① 뭐 하는 회사인지 — 사업보고서를 AI가 읽어 쉬운 말로 요약합니다. 모든 문장은 DART 근거이고, 없으면 '데이터 없음'으로 정직하게 둡니다."
- 🖱️ **계열사 관계도** 토글 → **재무 하이라이트**(매출·영업이익·당기순이익 + 전년比) → **주가 차트**.
- 🎙 "② 돈은 잘 버는지 — 매출·영업이익·순이익을 전년 동기와 비교해 보여주고, 재무 건전성·주주 구성·주가 흐름까지 한 화면입니다. 전부 DART·KRX 실데이터예요."

## 3. 밸류에이션 탭 — "③ 비싼가 싼가?"
- 🖱️ 스코어카드(동종 대비 싼/비싼) → **📚 밸류에이션 튜토리얼** 버튼(상단) → DCF·멀티플·WACC 풀이.
- 🎙 "③ 지금 사도 되나, 비싼가 싼가 — **네 가지 잣대로 교차검증**합니다. 옆 회사와 비교하는 상대가치(멀티플) 3개 + 회사가 앞으로 벌 돈을 계산하는 절대가치(DCF) 1개. **하나의 정답가가 아니라 범위**로 보여주고, 현재가와의 차이는 '시장의 기대'로 해석합니다."
- 🖱️ **'전문가용 자세히'** → **ROIC vs WACC** 블록.
- 🎙 "전문가용을 펼치면, 회사 수익률(ROIC)이 자본비용(WACC)을 넘는지까지 봅니다. 신뢰도가 낮으면 적정가 숫자를 일부러 숨겨 과신을 막습니다."

## 4. AI 챗봇 탭 — "④ 궁금한 건 그냥 물어봐"
- 🖱️ AI 챗봇 탭 → 질문 입력(예: **"삼성전기 주요 사업은?"** 또는 "1분기 매출은?") → 답변 + **출처 카드**(DART 회사명·보고서명·링크).
- 🎙 "④ 더 궁금하면 그냥 물어봅니다. 사업보고서를 검색해 **근거(출처)와 함께** 답하고, 없으면 '찾을 수 없다'고 합니다. 숫자는 원문 링크로 직접 확인하세요 — 환각을 막는 구조입니다."

## 5. 관리자 페이지 — "PoC가 아니라 진짜 돌아가는 서비스" (신뢰성)
- 🖱️ `/admin` → **기업개요 운영** 탭(기능 모듈 현황·커버리지·DB·신선도·스모크) → **기업개요 검증** 탭.
- 🎙 "보이는 화면만이 아니라 **운영·검증 콘솔**까지 만들었습니다. 운영 탭은 어떤 데이터가 어디서 와서 지금 정상인지를, **검증 탭은 버튼 하나로** 재무 항등식·DART 원문 대조를 돌려 **오류율 0%**를 증명합니다."
- 🖱️ (검증 탭) 재무 파트 선택 → **[샘플 검증]** 클릭 → 오류율 0% → **[DART 원문 대조]**.
- 🎙 "말이 아니라 즉석에서 증명합니다. 밸류·챗봇 운영/테스트 탭도 별도로 있습니다. (상세 = 기업개요 관리자 매뉴얼 참고)"

## 6. 마무리 — "⑤ 그래서, 내가 판단한다"
- 🎙 "다섯 질문에 차례로 답하면, 마지막엔 **스스로 판단**하게 됩니다. 전문가의 정보를, 모두에게 — 허위정보 없이, 출처와 함께, 불확실하면 숨기는 **NO-MOCK** 서비스입니다."
