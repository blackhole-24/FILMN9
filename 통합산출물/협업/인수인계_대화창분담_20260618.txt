[0] ★★★ 최우선 규칙 — GPU / CPU 사용 권한 (반드시 지킬 것) ★★★
────────────────────────────────────────────────────────────────────────────
- 이 "메인 창"(작성자)만 GPU + CPU 를 모두 사용한다.
- 다른 모든 대화창(인수받는 창 B, C, …)은 **CPU만 사용**한다. GPU 금지.
- 이유: 챗봇은 AWS GPU EC2(g4dn, ~$0.5/h)에서 도는데 비용이 직접 나가고,
  GPU는 사용자가 "챗봇 GPU 켜줘"라고 명시할 때만 켜는 엄격한 규칙이 있다.
- 따라서:
  * 챗봇 GPU 배포/기동/시연/정지 같은 GPU 관련 작업은 **메인 창에서만** 한다.
  * 다른 창은 절대로 GPU EC2 를 start 하지 않는다. "챗봇 GPU 켜줘"를 실행하지
    않는다. "서버 다 켜줘" 류 요청에도 GPU 는 제외한다.
  * 다른 창의 작업(PM/PPT/스크립트/문서/프론트엔드 코드)은 전부 CPU만으로 충분.
- 로컬 임베딩·리랭킹 등 GPU가 필요한 무거운 연산도 다른 창에서는 돌리지 말 것
  (필요하면 메인 창에 요청). 다른 창은 DB 조회·문서·코드·빌드(CPU)만.

[5] 절대 지켜야 할 공통 규칙 (모든 창)
────────────────────────────────────────────────────────────────────────────
1. NO-MOCK / 무할루시네이션: 가짜 숫자·임의 문장 단 하나도 생성 금지. 근거(DART·DB·
   계산식) 없는 값은 표시 안 함. 데이터 없으면 "데이터 없음"으로 정직 표기.
2. GitHub 실명 금지: 사람 이름 대신 "파트명" 사용. 밸류에이션 파트 / 기업개요 파트.
   (메모리 내부 기록에서만 실명 OK)
3. OpenAI 등 유료 API 호출 전 반드시 사용자에게 예상 비용($) 사전 고지. 무료(로컬
   임베딩·DB조회 등)는 해당 없음. (단 로컬 GPU 임베딩은 다른 창에서 돌리지 말 것 — [0])
4. 보안: 어떤 API 키도(.env의 OPENAI_API_KEY 등) 다른 파일/채팅/캡처로 복사·노출·
   하드코딩 금지. 프로그램은 .env를 런타임에 "읽기만". .env는 항상 .gitignore.
   이 인수인계서를 비롯한 어떤 산출물에도 실제 키 값을 적지 않는다.
5. git push 전 보안 4중 체크: ①git status에 .env류 없음 ②diff에 sk-/키패턴 0건
   ③.env 실제값 역대조 0건 ④push 범위 diff에 키·.env 0건 → 통과 후에만 push.
   * 메인(main)에서 직접 작업 중이면 푸시는 코드 동결 시점에. 브랜치 사용 권장.
6. 작업리스트는 표/보드로 그릴 때 "소요(ETA)" 컬럼 항상 필수(요약·필터해도 생략 금지).
7. PPT 장표는 "AI 티" 나면 안 됨(사람이 만든 듯 자연스럽게) — 필수 규칙.
8. 발표 자료 3장표 이름 고정: "개발원가" / "수익모델+BEP" / "AI 기술 활용" (Appendix).
