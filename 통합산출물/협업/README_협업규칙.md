## 이 폴더의 파일
- `작업리스트_공유.md` — 마스터 작업리스트·스케줄. **모든 창이 같은 표를 보고 갱신**한다.
- `인수인계_대화창분담_20260618.txt` — 분담·규칙·읽을 폴더 안내(상세).
- `README_협업규칙.md` — (이 파일) 공유 규칙.

## ★ 공유 협업 규칙 (3개 창 공통, 반드시 지킬 것)
1. **작업 시작 전 반드시 `git pull`** — 다른 창이 갱신한 최신 작업리스트를 먼저 받는다.
2. **하나의 작업이 끝나면 즉시** 다음을 한다(미루지 말 것):
   1. `작업리스트_공유.md` 의 해당 행 상태 갱신 (⬜→🔄→✅, 비고에 결과 한 줄)
   2. `git add 통합산출물/협업/`
   3. `git commit -m "작업리스트: <항목> 완료 (창B 또는 창C)"`
   4. `git push`
   → 다른 창은 `git pull` 만 하면 **누가 무엇을 끝냈는지 즉시** 확인한다.
3. **코드(소스) 변경 커밋 시 보안 4중 점검 필수**:
   ① `git status` 에 `.env` 없음 ② diff 에 `sk-`/키패턴 0건 ③ `.env` 실제값 역대조 0건 ④ push 범위 0건.
   문서만 커밋이면 ①②만 빠르게 확인.
4. **공유 브랜치 = `main`**. push 충돌 시 `git pull --rebase` 후 재push.
5. **GPU(챗봇 EC2)는 창A만 사용.** 창B·창C는 CPU만 (GPU start·"챗봇 GPU 켜줘" 금지).
