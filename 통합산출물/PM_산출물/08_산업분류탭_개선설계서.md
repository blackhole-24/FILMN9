# 산업분류(WICS) 탭 — 개선 설계서

문서버전 v1.0 · 2026-06-05 · 트리거: "산업분류 개선사항"

> 현재 `/sectors` 탭은 WICS(FnGuide) 소분류 78·중분류 29 기준으로 구현됨
> (`backend/routers/sectors.py`, `frontend/app/sectors/`). 아래 6개 개선안.

---

## 현재 구현 요약
- 데이터: WICS(ticker_universe), 소분류 78 · 중분류 29.
- API: `/api/sectors`, `/{업종}/stocks`, extras `/sectors/search`(유사어).
- 검색: 부분일치 + 유사어(예: 방산→우주항공과국방).

## 개선 6항목

### ① 분류 출처·개수 명확화
- WICS(FnGuide) 소분류 78·중분류 29 (네이버 아님)임을 화면/문서에 명시.
- 신뢰 소스 표기로 NO-MOCK 일관성.

### ② "반도체와반도체장비" 분리 보류
- 임의 분리는 NO-MOCK 위반 → 데모까진 WICS 원본 유지.
- 추후: 신뢰 소스 확보 후 2단계(반도체/반도체장비) 토글 제공.

### ③ 종목 정렬: 시가총액 내림차순
- 현재 종목코드 오름차순 → **추천: 시총 내림차순(대장주 먼저)**.
- 구현: 종목 리스트 응답에 시총(주가×주식수 추정) 조인 후 정렬.
- 난이도 낮음(SP 1). API 정렬 파라미터 `?sort=mktcap`.

### ④ 산업 표시명 정리
- WICS 키(조인용)는 유지 + **표시명 매핑**으로 라벨만 정리(쉼표→가운뎃점 등).
- 예: "반도체와반도체장비" → 표시 "반도체·반도체장비".
- NO-MOCK 안전(키 불변, 라벨만).

### ⑤ 검색 정확도 향상
- 현재: 부분일치 + 유사어. **추가**: rapidfuzz 오타허용, Enter로 첫 결과 열기,
  키워드 사전 확충(wics_keywords 보강).

### ⑥ 뒤로가기 UX
- 브레드크럼(홈 > 산업분류 > 업종 > 종목) + 고정 뒤로가기 버튼.
- 이전 검색어·스크롤 위치 복원(상태 보존).
