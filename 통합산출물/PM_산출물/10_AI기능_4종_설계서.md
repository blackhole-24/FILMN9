# AI 기능 4종 — 설계서

문서버전 v1.0 · 2026-06-05 · (5/20 미완 항목 정식화)

> FINSIGHT에 적용/검토되는 AI 기능을 4종으로 정리. 각 기능의 목적·입력/출력·모델·
> 데이터·비용·신뢰성(NO-MOCK)·상태.

---

## AI-1. 히스토리 브리핑 (기업 스토리 생성) — ✅ 운영
- 목적: 기업의 사업·연혁·핵심을 투자자 친화적 스토리로 LLM 생성.
- 입력: 사업보고서/기업개요 → 출력: 브리핑 텍스트(MongoDB histories).
- 모델: LLM 생성 + 평가(`evaluate.py` 4-Phase: 수치/인용/RAGAS/LLM Judge).
- 신뢰성: overall_score·등급(평균 77.1), 저점수 2-pass 재생성(merge_best).
- 비용: 생성 시 LLM 호출(배치, 사전 고지 대상).

## AI-2. 사업보고서 RAG 챗봇 — ✅ 운영(8800 MSA)
- 목적: 사업보고서 근거로 자연어 질의응답.
- 파이프라인: 청킹 → BGE-M3 임베딩(1024d, ChromaDB ~192만 청크) →
  bge-reranker-v2-m3 리랭킹 → gpt-5-mini 생성 → SSE 스트리밍.
- 출력: 답변 + 출처 카드 + DART 링크. 근거 없으면 "찾을 수 없음".
- 비용: 질의당 ~5원(gpt-5-mini). 임베딩/리랭킹은 로컬 GPU(무료).
- 개선: 하이브리드(BM25+벡터) 쿼리 고도화(팀원, 진행).

## AI-3. DCF 밸류에이션 보조 분석 — ✅ 부분(엔진 v8)
- 목적: 적정주가 산출 + 쉬운 해설("이 주식 지금 가격이 적당할까?").
- 입력: 재무/시장/금리 → 출력: 적정주가·WACC·민감도·피어(JSON) + 자연어 설명.
- 모델: 엔진(DCF/Multiples/Peer 자동선정) + 설명용 LLM(선택).
- 신뢰성: 계산식 역검증, current_price 정합성(검증 대상).
- 확장: 애널리스트 PDF 컨센서스(gpt-4o-mini, 유료, 보류).

## AI-4. 신뢰도 검증 자동화(LLM Judge) — ⬜ 설계
- 목적: 화면 표시값이 원본과 일치하는지 자동 채점(관리자 신뢰도 검증 탭의 엔진).
- 방법: 숫자 매칭(DART↔DB) + RAGAS(챗봇) + LLM Judge(인용/사실성) + 항등식 검사.
- 출력: 파트별 오류율(%)·실패 항목·근거. 재사용: 히스토리브리핑 evaluate.py.
- 비용: LLM Judge 사용 시 호출 비용(사전 고지) — 숫자 매칭은 무료 우선.

---
### 공통 원칙
- **NO-MOCK**: 모든 AI 출력은 근거(원문/계산식) 동반, 불확실 시 "데이터 없음".
- **비용 통제**: 유료 LLM 호출 전 예상 비용($) 사전 고지·승인. 로컬 GPU 우선.
- **분리(MSA)**: 무거운 RAG는 별도 서버(8800/GPU)로 격리.
