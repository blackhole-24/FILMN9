# FINSIGHT 프로젝트 헌장 (Project Charter)

문서버전 v1.0 · 2026-06-05 · 운영 FILMN9 Inc. · KPMG AI Lab

---

## 1. 프로젝트명
FINSIGHT — KOSPI·KOSDAQ 상장사 AI 기업분석·가치평가 플랫폼

## 2. 목적 / 배경
- 개인 투자자는 공시·재무·밸류에이션을 직접 종합 분석하기 어렵다.
- DART 공시 + 재무 + 주가 + LLM/RAG + DCF 밸류에이션을 한 화면에 통합해
  **"기업 분석, 이제 5분 만에"**를 실현한다.
- 약 2,600개 상장사를 사전계산·배치로 커버하여 즉시 분석 경험을 제공한다.

## 3. 목표 / 성공 기준
| 목표 | 측정 지표 |
|---|---|
| 종합 분석 화면 제공 | 종목 상세 3탭(기업개요·밸류·AI챗봇) 정상 작동 |
| 데이터 신뢰성(NO-MOCK) | 신뢰도 검증 오류율 ≈ 0, 근거 없는 표시 0건 |
| 커버리지 | 기준 2,580종목 핵심필드 결측 0%, Sankey ~2,627 |
| AI 활용 | 사업보고서 RAG 챗봇(192만 청크) 근거 기반 답변 |
| 데모 | 6/5 KPMG AI Lab 데모, 6/20 최종 발표 |

## 4. 범위 (Scope)
### In-scope
- 메인 홈/검색, 산업(WICS) 탐색, 종목 상세 3탭, 모닝 시그널, 밸류 요약,
  계열사 시각화, AI RAG 챗봇, 관리자 페이지(모니터링·신뢰도 검증).
### Out-of-scope (현 단계)
- 실시간 트레이딩/주문, 유료 결제, 개인화 포트폴리오 자동매매, 해외 상장사.
