# FINSIGHT 페르소나

문서버전 v1.0 · 2026-06-05

> 서비스 사용자는 **일반 투자자 1종**으로 단순화(시스템 아키텍처 합의). 내부 운영을 위한
> 관리자 페르소나를 보조로 정의한다.

---

## P1. 주 사용자 — 일반 투자자 "김현우" (35, 직장인)
- **상황**: 국내 주식에 관심은 많지만, 공시·재무제표·밸류에이션을 직접 해석할 시간이 없다.
- **목표**
  - 관심 종목의 사업·실적·적정주가를 **5분 안에** 파악.
  - 어려운 재무·밸류 용어를 쉬운 설명으로 이해.
- **페인포인트**
  - DART 원문은 방대하고 어렵다. 증권사 리포트는 일부 종목만.
  - 적정주가 판단 근거가 불투명하다. 가짜/추정 정보가 불안하다.
- **핵심 시나리오**
  1. 기업명 검색 → 종목 상세 진입.
  2. 기업개요 탭에서 히스토리 브리핑·손익흐름도·계열사·재무 하이라이트 확인.
  3. 밸류에이션 탭에서 적정주가(Bear/Base/Bull)·상승여력·WACC 확인.
  4. AI 챗봇에 "이 회사 주력 사업은?" 질문 → 사업보고서 근거로 답변.
- **FINSIGHT 가치**: NO-MOCK 근거 기반 + 5분 종합 분석 + 쉬운 설명.

## P2. 업종 탐색형 투자자 "이서연" (29, 사회초년생)
- **상황**: 특정 종목보다 "어떤 산업이 유망한가"부터 탐색.
- **목표**: 업종 → 대표 종목 → 밸류 요약으로 후보 압축.
- **시나리오**: 산업(WICS) 탐색 → 제약 업종 → 대표주 밸류 요약 → 상세 비교.
- **개선 니즈**: 업종 내 시총 내림차순 정렬, 오타허용 검색, 브레드크럼.

## P3. (내부) 운영 관리자 "박운영"
- **상황**: 데이터가 여러 원천에서 배치/실시간 유입 → 상태·신뢰도 점검 필요.
- **목표**
  - 서버/DB/배치/캐시/커버리지를 한 화면에서 모니터링.
  - 파트별(브리핑·재무·밸류·챗봇·계열사) 신뢰도 오류율 검증.
- **시나리오**: 관리자 페이지 탭1 헬스/신선도 확인 → 탭2 샘플 신뢰도 검증 → 오류 항목 조치.
- **가치**: NO-MOCK 운영 보증, 데이터 갱신·비용 관리.
