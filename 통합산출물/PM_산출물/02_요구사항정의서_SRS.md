# FINSIGHT 요구사항 정의서 (SRS)

문서버전 v1.0 · 2026-06-05 · 서비스: FINSIGHT (운영 FILMN9 Inc.)

---

## 1. 제품 개요
- 정의: KOSPI·KOSDAQ 약 2,600개 상장사를 개인 투자자도 기관 수준으로 분석하도록 돕는
  AI 기업분석·가치평가 플랫폼. 슬로건 "기업 분석, 이제 5분 만에".
- 가치: DART 공시 + 재무 + 주가 + LLM/RAG + DCF 밸류에이션을 한 화면에 통합.
- 핵심 원칙: **NO-MOCK** — 근거 없는 수치/문장 표시 금지, 없으면 "데이터 없음".

## 2. 기능 요구사항 (FR)

### FR-1 검색 / 진입
- FR-1.1 기업명·종목코드 검색(부분일치+유사어), Enter로 첫 결과 진입.
- FR-1.2 메인 홈: 모닝 마켓 시그널 위젯, 밸류 요약, 산업 탐색 입구, 추천 종목 슬라이드 캐러셀.

### FR-2 산업(업종) 탐색
- FR-2.1 WICS 78개 업종 그리드 + 업종별 종목수.
- FR-2.2 업종 선택 → 종목 리스트(추천: 시총 내림차순), 종목 클릭 → 상세.
- FR-2.3 검색 정확도(오타허용), 브레드크럼/뒤로가기.

### FR-3 종목 상세 — Tab1 기업개요
- 히스토리 브리핑(LLM), 최신 뉴스, 계열회사 구조(토글), 주가차트(일봉/거래량),
  재무 하이라이트, 재무건전성, 주주구성, 손익흐름도(Sankey)/BS/IS, 경영인, 최근 공시, DART 뷰어.

### FR-4 종목 상세 — Tab2 밸류에이션
- DCF(FCFF) 적정주가 Bear/Base/Bull, WACC, 멀티플(PER/PBR/EV·EBITDA), 민감도·토네이도,
  피어 비교, EPV/역산성장률. 데이터 없으면 "준비중".

### FR-5 종목 상세 — Tab3 AI 챗봇
- 사업보고서 RAG 챗봇(별도 8800 MSA) 임베드. 출처 카드·DART 링크·세션 유지·SSE 스트리밍.

### FR-6 모닝 마켓 시그널
- 글로벌 야간시장 23지표 + 신호등6 + 종합판정, 15분 캐시.

### FR-7 관리자(내부)
- 운영 모니터링(헬스·DB·신선도·커버리지) + 신뢰도 검증(파트별 오류율). 별도 설계서 참조.

## 3. 비기능 요구사항 (NFR)
| 코드 | 분류 | 요구 |
|---|---|---|
| NFR-1 | 신뢰성 | NO-MOCK: 모든 수치/문장 근거(DART·DB·계산식) 필수, 할루시네이션 0 |
| NFR-2 | 성능 | 모닝 위젯 prewarm+자동갱신으로 콜드스타트 회피, 종목 상세 체감 5분 내 분석 |
| NFR-3 | 확장성 | AI 챗봇은 별도 MSA(8800/GPU), 메인 API와 자원·배포 분리 |
| NFR-4 | 보안 | .env 시크릿 분리(코드/Git 금지), CORS 제한, HTTPS/WAF/IAM 최소권한 |
| NFR-5 | 신선도 | 주가=매 거래일 16:00 배치, 공시/재무=시즌, 밸류/계열사=사전배치 |
| NFR-6 | 가용성 | 사전생성(Sankey/밸류 JSON) 서빙으로 요청 시 즉석계산 부하 회피 |
| NFR-7 | 운영성 | healthcheck 전수검수, 관리자 페이지로 상태·신뢰도 가시화 |

## 4. 데이터 요구사항
- 정형(RDB): 기업개요·재무·주가·주주·경영인·공시·신용등급·WICS유사어·밸류요약·거래정지.
- 문서(MongoDB): 히스토리 브리핑.
- 벡터(ChromaDB): 사업보고서 임베딩 ~192만 청크.
- 객체(S3/파일): Sankey HTML ~2,600 · 밸류 JSON · 계열사 SVG.
- 공통 키: 6자리 stock_code.

## 5. 외부 인터페이스
- DART OpenAPI(공시·XBRL), OpenAI(gpt-5-mini/gpt-4o-mini), yfinance/KRX/pykrx(주가),
  ECOS/KOFIA(금리), 네이버(뉴스·환율), WICS/FnGuide(업종).

## 6. 제약 사항
- 데모 데이터 셋은 2026 타임라인 기준. 밸류 전수취합은 종목당 고비용 → 단계적.
- OpenAI 유료 호출은 사전 비용 고지·승인 후. 팀 공유 잔액 한도 주의.

## 7. 수용 기준(샘플)
- 임의 종목 상세 진입 시 기업개요 핵심필드 결측 0%, 손익흐름도·차트 정상 렌더.
- 신뢰도 검증 샘플에서 숫자 불일치 0건, 챗봇 근거 없는 답변 0건.
