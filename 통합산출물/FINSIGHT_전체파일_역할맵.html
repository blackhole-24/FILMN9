FINSIGHT 전체 파일 역할맵

FILMN9 폴더의 주요 파일이 각각 무슨 역할을 하는지 한 줄로 — 코드 해석이 아니라 "큰 흐름"용

2026-06-14 · 발표/이해용 · 상세 데이터흐름은 데이터원천지도 v2 참조
💡 읽는 법: backend=데이터를 꺼내주는 서버, frontend=화면, 루트 스크립트=데이터를 모아 DB에 쌓는 도구(대부분 1회 실행). 파일명 앞 단어가 보통 역할(build=생성, fetch/load=수집·적재, parse=파싱, check=점검).

🖥️ 백엔드 (FastAPI · 데이터를 꺼내 가공해 주는 서버 :8090)

파일역할
backend/main.py서버 진입점. 모든 라우터를 등록하고, 손익흐름도 HTML(/sankey/{code})을 직접 서빙. CORS 설정.
backend/db.py★DB 연결 추상화. SQLite(로컬)↔PostgreSQL(AWS)를 .env의 DB_BACKEND로 전환. psycopg 래퍼(? →%s 변환 등).
routers/overview.py기업개요 종합(/api/overview). 재무 하이라이트·건전성·주주·경영인 + Mongo 히스토리브리핑을 한 번에 묶어 반환.
routers/extras.py재무제표 상세(/api/financial_detail/{code}/BS·IS, 3개년 피벗) + 공급계약 등 부가.
routers/valuation.py밸류 상세(/api/valuation·valuation-full) — 엔진 합본 JSON 반환(대시보드 iframe용).
routers/valuation_summary.py밸류 요약 랭킹(/api/valuation-summary) — 2,224종 적정가·신뢰도·현재가 정렬.
routers/sectors.py산업분류 탐색(/api/sectors) + 메인 추천 캐러셀(/featured).
routers/morning.py글로벌 마켓 시그널(/api/morning) — yfinance 41지표 실시간+캐시·자동갱신.
routers/ohlcv.py주가 일봉 차트 데이터(/api/ohlcv/{code}).
routers/admin.py관리자(운영 모니터링·신뢰도 검증) + verify_admin 비밀번호 인증(X-Admin-Token).
routers/affiliate.py계열회사 구조 SVG/이미지(/api/affiliate/{code}).
routers/company.py회사 기본정보 조회.
