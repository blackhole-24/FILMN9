■ 기술 스택
- 프론트엔드: Next.js 16 (React 19) — 종목 상세 3탭(기업개요·밸류에이션·AI챗봇)
- 백엔드: FastAPI (Python) — REST API
- AI 챗봇: 별도 RAG 서버 (ChromaDB 벡터검색 + LLM)
- 데이터베이스(하이브리드 4종):
  · 관계형: SQLite → Supabase PostgreSQL 이관 완료 (16테이블, 약 1,175만 행)
  · 벡터: ChromaDB (사업보고서 임베딩, 약 377만 청크, ~40GB, GPU 검색/리랭킹)
  · 문서: MongoDB Atlas (AI 히스토리 브리핑 본문)
  · 파일: 손익흐름도 HTML·밸류 결과 JSON·계열사 이미지
- 외부 데이터원: DART OpenAPI(재무·공시·지분), yfinance·pykrx(주가), ECOS(금리),
  WICS(산업분류), 네이버 뉴스 API, OpenAI API(챗봇·요약)
