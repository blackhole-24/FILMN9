MCP가 뭐예요?

MCP(Model Context Protocol) = AI(클로드 등)가 우리 FINSIGHT 데이터를 표준화된 "도구(tool)"로 직접 불러 쓰게 해주는 규격입니다.

비유

지금 우리 서비스는 사람이 웹 화면으로 봅니다. MCP를 깔면 AI 비서가 우리 DB를 API처럼 물어볼 수 있습니다. 마치 우리 데이터에 "AI 전용 콘센트"를 달아주는 것.

예시 흐름

  • 사용자가 클로드에게 "삼성전자 재무 어때?"
  • 클로드가 우리 MCP의 get_financials("005930") 도구 호출
  • MCP 서버가 RDS에서 3년치 재무를 꺼내 클로드에게 전달
  • 클로드가 자연어로 답변 (우리 데이터 기반)

AWS 배포 전에 필요한가?

아니오 — 독립 MCP는 배포와 무관한 부가 기능입니다. 발표에서 "AI가 우리 데이터를 직접 쓴다"는 아키텍처 어필용으로 좋지만, 배포의 선행조건은 아닙니다. 배포 후 추가하면 됩니다.
