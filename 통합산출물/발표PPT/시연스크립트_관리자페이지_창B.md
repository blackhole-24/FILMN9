> "첫 번째 탭은 **운영 상태판**입니다. 서비스가 지금 정상인지, 데이터가 며칠 자(字)인지를 한눈에 봅니다. 위에서 아래로 훑어보겠습니다."

| 박스 | 역할 (무엇을) | 의미·해석 (어떻게 읽나) |
|---|---|---|
| **🗺️ 기능 모듈 운영 현황** | 메인·기업개요·밸류·챗봇의 각 기능이 **어느 원천에서 → 어떻게 화면까지** 오는지 + 지금 정상 작동 중인지 | "이 기능은 DART에서 받아 이 API로 화면에 그린다"는 **데이터 계보(lineage)**. 초록이면 정상 가동. 화면 기능과 데이터 출처가 1:1로 투명하게 연결돼 있음을 보여줌 |

| **🗃️ 데이터 관리 (신선도·갱신 시점)** | 각 데이터가 **언제 기준·어디서·자동/수동** 갱신인지 표 | 주가는 매일 16:30 자동, 재무는 공시 때 등 — **갱신 주기가 데이터 성격에 맞게 설계**됐음을 보여줌 |

| **🤖 AI 챗봇 운영 (RAG)** | 챗봇 서버의 실시간 상태·구성·**비용** (GPU $/시간, 질의당 ~5원) | 🟢가동/워밍업/정지 상태 표시. **임베딩·리랭킹은 로컬 GPU(무료), LLM 답변만 유료**라는 저비용 구조를 숫자로 |
| **🖥️ 서비스 생존 (Liveness)** | 백엔드·프론트·챗봇 **포트 연결 + 응답시간** | 신호등처럼 살아있는지 + 얼마나 빠른지. 운영자가 장애를 즉시 발견하는 곳 |
| **📊 종목 커버리지** | 기준 종목 수 대비 각 기능이 **몇 %를 커버**하는지 | 주주 100%·재무 99%처럼 — "전 종목 보장"을 수치로. 낮은 항목은 NO-MOCK 갭(가짜로 안 채움) |
| **🗄️ DB 현황 (16테이블)** | `filmn9.db`/RDS 각 테이블 **행수** | 총 약 1,175만 행. 빈 테이블(0행)은 빨강 — 스키마는 있되 미적재(정직 표기). 대부분 행은 주가(ohlcv)가 차지 |
| **⏱️ 데이터 신선도 (Freshness)** | 원천별 **가장 최근 갱신 시각** (MAX 날짜) | 오래되면 갱신 신호. 주가=MAX(date), 재무=loaded_at, 밸류=as_of_date로 계산 |
| **🔎 스모크 테스트** | 샘플 종목의 핵심 데이터가 실제로 나오는지 빠른 점검 | "대표 종목 눌러보니 다 나온다"는 즉석 확인 |
| **🛠️ 유지보수** | 운영자용 관리 동작 | 일상 점검·보수용 |

> **시연 멘트**: "운영 탭은 한마디로 **'우리 서비스의 건강검진표'**입니다. 어떤 기능이 어디서 데이터를 받아 지금 정상인지, 데이터가 며칠 자인지, 비용이 얼마인지 — 운영자가 매일 5분이면 전체 상태를 파악합니다."

## ✅ 탭 2. 기업분석 · 검증 — "이 데이터가 진짜인지 직접 검사한다" (★최대 강조)

> "두 번째 탭이 저희가 **가장 자신 있는 부분**입니다. 데이터가 '있다'를 넘어 **'맞다'**를 증명하는 5단계 검증입니다. 버튼을 누르면 실제로 검사가 돕니다."

| 검증 | 역할 (무엇을 검사) | 의미·해석 |
|---|---|---|
| **① 내부 정합성 검증** | DB 값 자체의 **논리 검사** — 재무 항등식(자산=부채+자본)·주가 OHLC 유효성(고가≥저가 등)·기업개요 완전성·밸류 상승여력 정합성. **샘플/전수** 선택 | "숫자들끼리 앞뒤가 맞는가"를 기계적으로 검사. 전수 검증으로 전 종목을 한 번에 점검 |
| **② DART 원문 대조** | 화면의 **요약 재무 ↔ DART XBRL 원문**을 맞대어 비교 | 우리가 보여주는 숫자가 **금감원 공시 원본과 일치**하는지 — 할루시네이션이 아님을 원천으로 증명 |
| **③ 히스토리브리핑 신뢰도** | AI가 쓴 브리핑을 **4-Phase로 자동 채점**(수치 매칭·인용 검증·RAGAS·LLM Judge) | 평균 77.1점·2,526종. "AI 요약을 AI가 다시 검증"하는 이중 안전장치. 저점수는 재생성 |
| **④ AI 챗봇 검증 (RAG)** | 챗봇의 지식베이스·서버 상태 점검 (무료) | 챗봇이 학습한 보고서량·검색이 살아있는지 |
| **⑤ 계열사 검증** | 계열사 시각화 **파일 커버리지·무결성**(크기>0·SVG 정상) | 그림 파일이 깨지지 않았는지. 현재 GitHub 샘플만 → 낮은 커버리지는 정상 |

> **시연 멘트**: "①은 숫자끼리 논리가 맞는지, ②는 그 숫자가 **DART 원문과 같은지**, ③은 AI 글의 신뢰도, ④는 챗봇, ⑤는 그림 파일 — **5개 파트를 원본과 대조**합니다.
> 특히 ② DART 원문 대조가 핵심입니다. 'AI가 지어낸 거 아니냐'는 의심에, 저희는 **버튼 하나로 공시 원문과 대조해 오류율을 보여드립니다.** 이게 NO-MOCK을 구호가 아니라 **증명**으로 만드는 장치입니다."

## 💰 탭 3. 밸류에이션 · 운영 — "어떤 데이터로, 언제, 어디서 평가했나" *(태상님 매뉴얼 기반)*

> "세 번째 탭은 밸류에이션 **투명성 상태판**입니다. 적정주가를 만든 재료와 출처를 숨김없이 공개합니다. 네 부분입니다."

| 부분 | 역할 | 의미·해석 |
|---|---|---|
| **① 데이터 기준일** | 평가에 쓴 데이터가 **며칠 자**인지 (카드 3장: 밸류·기업개요·챗봇) | **평가 기준일·금리(Rf 4.118%)·시가총액 세 날짜가 서로 가까운지**가 핵심. 벌어져 있으면 그 사이 시장 변화가 빠진 것 → 재평가 필요. 모델 v9·약 2,231종 |
| **② 데이터 출처** | 쓰는 데이터 **출처 8곳** 명시 | 재무=DART, 주가·시총=거래소(KRX), 금리=한국은행(ECOS)… **전부 공식 출처.** "임의로 안 지어낸다"의 근거 |
| **③ 테스트 환경** | 엔진 방법(DCF·EPV·멀티플)·챗봇 검색 순서·서버 사양 | 기술 질문 대비 사양표 |
| **④ AI 하네스** ★ | **AI가 거짓말 못 하게 막는 4중 장치** | (1)없으면 비워둠 (2)AI는 '찾기'만·'판단'은 정해진 규칙 (3)모든 숫자에 출처 (4)확신 약하면 숨김(범위만). **이 서비스의 핵심 자랑** |

> **시연 멘트**: "이 화면은 '저희가 **어떤 데이터를, 언제 기준으로, 어디서 받아** 만들었는지'를 평가위원께서 직접 확인하시는 곳입니다. 약 2,200종목을 6월 16일 데이터로 평가했고, 금리·회사채·시총 **세 날짜를 숨기지 않고** 그대로 보여드립니다. 마지막 ④ **AI 하네스**가 가장 강조하고 싶은 부분입니다 — AI가 숫자를 지어내지 못하게, 없으면 비우고, 찾기만 맡기고, 출처를 붙이고, 확신 없으면 숨깁니다."

## 🧪 탭 4. 밸류에이션 · 테스트 — "진짜 도는지 직접 눌러본다" *(태상님 매뉴얼 기반)*

> "마지막은 **점검판**입니다. 말이 아니라 직접 버튼을 눌러 살아있음을 보여드립니다."

| 박스 | 역할 | 의미·해석 |
|---|---|---|
| **시스템 상태 (신호등 3개)** | 백엔드(:8090)·챗봇(:8800)·프론트(:3000) 생존 | 초록=정상·빨강=응답없음·회색=확인중. 챗봇은 GPU 깨어날 때 잠깐 빨강일 수 있음(정상) |
| **🧪 밸류에이션 QA** | 종목코드 넣고 [밸류 검증] → 적정주가·현재가·WACC·신뢰도 등급·EPV + **다섯 가지 체크(✓/✗)** | 다섯 개 모두 ✓면 **완전하게 평가된 종목**. 미평가 종목은 '준비 중'(정상). 대표 종목인데 ✗ 많으면 엔진 이상 신호 |
| **🤖 챗봇 QA** | 질문 넣고 [질의] → AI 답변 + **DART 원문 출처** | 핵심은 '답에 출처가 붙느냐'. 출처 없이 단정하는 답은 신뢰하지 않음. (첫 답변 수십 초·질의당 ~5원) |
| **✅ QA 체크리스트** | 매번 점검할 5가지 | ①없는 값은 '준비 중'? ②일부 빠져도 화면 안 깨짐? ③챗봇 답에 출처? ④날짜 최신? ⑤신뢰도 등급 표시? |

> **시연 멘트**: "이 탭은 **직접 눌러 확인하는 곳**입니다. 신호등 세 개가 초록인 걸 보고, 종목 하나를 검증하면 적정주가·WACC·등급과 함께 **꼭 있어야 할 항목 다섯 개가 전부 체크**됩니다. 아직 평가 안 한 종목은 가짜 숫자 대신 **'준비 중'**으로 정직하게 나옵니다. 저희 원칙은 한 문장입니다 — **'실제 데이터만, 출처와 함께, 확신이 없으면 숨긴다.'**"

## 🎬 마무리 멘트 (관리자 페이지 클로징) — 20초

> "정리하면, 일반 화면이 **'사용자가 보는 결과'**라면 이 관리자 페이지는 **'저희가 그 결과를 어떻게 책임지는가'**입니다.
> 운영 탭으로 **상태를 감시**하고, 검증 탭으로 **데이터를 원본과 대조**하고, 밸류 탭으로 **AI의 거짓을 차단**합니다.
> 저희가 끝까지 지킨 한 문장으로 마치겠습니다 — **'추정하지 않습니다, 출처로 말합니다.'**"

### 📌 시연 동선 팁 (관리자 파트, 약 3~4분)
1. `/admin` 접속 → "내부 통제판입니다" (NO-MOCK 한 줄 언급)
2. **운영 탭**: 🗺️기능모듈 → 📊커버리지 → 🤖챗봇 비용 (위→아래 드래그하며 "상태판")
3. **검증 탭**: ② DART 원문 대조 **버튼 실제 클릭**(가장 강조) → 5단계 설명
4. **밸류 운영 탭**: ④ AI 하네스 강조
5. **밸류 테스트 탭**: 신호등 → 밸류 QA 종목 1개 검증 실연 → "준비 중=정직"
6. 클로징: "추정하지 않습니다, 출처로 말합니다."
