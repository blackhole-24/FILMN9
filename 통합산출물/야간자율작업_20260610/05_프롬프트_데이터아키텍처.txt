당신은 오라클·구글 출신 40년차 데이터 아키텍트(Chief Data Architect)이자
컴퓨터공학과 교수입니다. 아래 서비스의 **데이터 아키텍처 다이어그램**을,
"데이터를 어떤 저장소에 어떤 형태로 두고, 현재→미래로 어떻게 이관하며,
어떻게 품질·신선도를 관리하는가" 라는 **데이터 저장 전략·거버넌스 관점**
1장으로 그려주세요. (excalidraw / 손그림 톤)

★ 데이터 파이프라인(원천→가공→서빙 흐름)과 구분할 것.
  이 그림은 "데이터가 어디에·어떤 형태로 사는가(저장소 토폴로지)" + "이관 로드맵".

★ 1순위 목표: "현재(로컬 3종 DB) → 미래(Supabase) → 배포(AWS)" 이관 화살표.

────────────────────────────────────────────────────────────
■ 3개 영역을 좌→우로 (현재 → 이관 → 배포)
────────────────────────────────────────────────────────────
[① 현재(AS-IS) — 로컬 3종 저장소]
- 관계형: SQLite filmn9.db (16테이블, 약 1.45GB / 1,167만 행. ohlcv 1,067만행 최대)
- 문서: MongoDB Atlas (histories = 히스토리 브리핑)
- 벡터: ChromaDB (사업보고서 임베딩 약 377만 청크 / BGE-M3 1024차원)
- 파일: 로컬 파일 (Sankey HTML 약 2,600·밸류 결과 JSON·계열사 SVG)
- + 밸류 엔진 별도: valuation.db(수치) + results JSON + 밸류 ChromaDB

[② 이관(Migration) — Supabase 통합]
- Supabase = 관리형 PostgreSQL
  · 관계형 16테이블 → Postgres 테이블
  · MongoDB 문서 → JSONB 컬럼 (또는 Atlas 유지 = 하이브리드)
  · ChromaDB 벡터 → pgvector (대용량이라 별도 검토)
- 이관 방식: pgloader/COPY(데이터) + raw SQL 쿼리 psycopg 전환(코드)
- ⚠️ 무료 500MB vs ohlcv 대용량 → 요금제 결정 게이트

[③ 배포(TO-BE) — AWS]
- RDS PostgreSQL (관계형) · S3 (파일·Sankey·밸류 JSON·SVG) ·
  EC2-GPU의 벡터DB(또는 RDS pgvector) · ElastiCache(캐시)

────────────────────────────────────────────────────────────
■ 데이터 거버넌스 레이어 (하단 가로 띠)
────────────────────────────────────────────────────────────
- 공통 키: 6자리 종목코드(stock_code)로 전 저장소 정합.
- 데이터 분류: 정형(수치)=관계형 / 텍스트=문서·JSONB / 임베딩=벡터 / 대용량 비정형=파일·S3.
- 품질(NO-MOCK): healthcheck_full 전수검증 + 근거 없는 값 미표시.
- 신선도: 주가=매 거래일 16:00 / 공시·재무=사업보고서 시즌 / 밸류·브리핑=배치.
- 보안: .env 시크릿 분리(코드·Git 금지)·최소권한.

────────────────────────────────────────────────────────────
■ 화살표
────────────────────────────────────────────────────────────
- ①→②→③ 굵은 이관 화살표(각 저장소가 어디로 가는지 1:1 매핑선).
- SQLite→RDS, Mongo→JSONB, Chroma→pgvector, 파일→S3 를 색 구분해 명확히.
- 거버넌스 띠 → 전 영역에 적용(점선).
- 좌하단 범례: AS-IS / 이관 / TO-BE 색 + 저장소 유형 아이콘.

[디자인]
- ★반드시 한국어. 손그림 톤. 저장소는 원통(관계형)·문서(문서)·격자(벡터)·버킷(S3) 아이콘.
- 현재=회색, 이관=주황, 배포=초록 등 단계별 색. 과밀 금지·글자 크게.
- "데이터가 지금 어디 있고, 어디로 옮겨가는지" 5초 이해.
