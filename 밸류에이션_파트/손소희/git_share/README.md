
# xbrl_financials_v3

DART OpenAPI의 XBRL 원본파일 + 택사노미를 이용해 국내 상장기업의 핵심 재무지표를 범용으로 추출하는 Python 모듈입니다.

종목명 또는 종목코드와 회계연도만 입력하면 매출액, 영업이익, EBITDA, NWC, CAPEX, **IBD(이자발생부채)**, NOA 등을 자동 산출합니다.

---

## 추출 항목

| 구분 | 항목 |
|------|------|
| 손익 | 매출액, 영업이익, 당기순이익, D&A, EBITDA |
| 운전자본 | NWC (당기/전기), ΔNWC |
| 투자 | CAPEX |
| 재무 | **IBD** (단기차입금, 유동성장기부채, 유동리스부채, 비유동사채, 장기차입금, 비유동리스부채) |
| 자산 | NOA (순영업자산) |
| 참고 | NOPAT, FCFF, 한계세율 |

> 모든 금액은 **원(KRW)** 단위로 반환. 출력 시 억원으로 표시.

---

## 설치

```bash
pip install requests pandas lxml python-dotenv
```

DART API 키를 `.env` 파일에 설정합니다.

```
DART_API_KEY=your_api_key_here
```

> API 키 발급: https://opendart.fss.or.kr

---

## 사용법

### CLI (터미널)

```bash
# 종목명으로 조회 (2024 회계연도)
python xbrl_financials_v3.py {아모레퍼시픽} {2024}

# 종목코드로 조회
python xbrl_financials_v3.py {090430} {2024}

# 저장 폴더 지정
python xbrl_financials_v3.py {현대건설} {2025} --outdir ./output

# JSON 저장 없이 콘솔 출력만
python xbrl_financials_v3.py {현대건설} {2025} --no-save

# API 키 직접 전달
python xbrl_financials_v3.py {삼성전자} {2024} --api-key YOUR_KEY

```

## 재무제표 기준

- **연결(Consolidated) 우선** — 연결 context가 없으면 개별(Separate) 자동 대체
- 회계연도 기준: `year` 입력 시 해당 연도 사업보고서 사용 (익년도 3월경 공시분)
- 정정 보고서가 있는 경우 가장 최근 접수분 자동 선택

---

## LLM 역할 경계

수치 계산은 **Python에서만** 수행합니다. LLM은 추출·분류·요약 역할만 담당하며, IBD를 포함한 모든 재무 수치는 XBRL 원본 데이터를 파싱하여 직접 산출합니다.
