# 데이터 명세서 v1.1

기업가치 평가 시스템이 사용·생성하는 모든 데이터의 명세.
v1.0 대비 추가: KOFIA 회사채/CP CSV, 사업보고서 RAG 청크, 신용등급 추출.

---

## A. 외부 데이터 소스

### A-1. KRX OpenAPI — 주가·지수
- 엔드포인트: `https://data-dbg.krx.co.kr/svc/apis/sto/...`
- 환경변수: `krxdata` (소문자 — 사용자 지정)
- 호출 시점: 매 실행마다, 영업일 단위 자동 갱신
- 사용 필드:
  - `TDD_CLSPRC` — 일별 종가 (시가총액 산정용)
  - `ISU_SRT_CD` / `ISU_CD` — 종목코드 (12자리 ISIN은 자동 6자리 변환)
- 캐시 위치: `peer_beta/data/raw/stock_<MARKET>_<YYYYMMDD>.json`, `index_<MARKET>_<YYYYMMDD>.json`
- 캐시 정책: 빈 응답 비저장, hit/miss 통계 출력

### A-2. ECOS API — 무위험수익률 Rf
- 엔드포인트: `https://ecos.bok.or.kr/api/StatisticSearch/...`
- 환경변수: `ECOS_API_KEY`
- 통계: `817Y002` (시장금리) / 항목 `010210000` (국고채 10년) / 주기 D
- 호출 시점: 매 실행마다 (캐시 없음, 영업일 단위 자동 갱신)
- T일 미공시 시 직전 영업일 최대 7일 거슬러

### A-3. DART OpenAPI (팀원 모듈 `XBRL/xbrl_financials_v4.py`)
- 환경변수: `DART_API_KEY`
- 사용 엔드포인트:
  - `list.json` — 사업보고서 접수번호 조회
  - `fnlttXbrl.xml` — XBRL ZIP 다운로드
  - `xbrlTaxonomy.json` — 라벨 매핑
- 산출 필드 (회사·연도별 JSON):
  - 손익: 매출액, 영업이익, 당기순이익, 지배순이익
  - 현금흐름: D&A, EBITDA, CapEx (유형자산 Gross)
  - 재무상태: NWC_cur, NWC_pfy, ΔNWC, IBD (단기차입금·장기차입금·사채·리스부채), IBD_detail
  - NOA: NOA_RULES_FINAL_V3 5분류 (확실/기본/조건부/OA/별도처리)
  - 세금: 한계세율, 세율구간
  - 파생: NOPAT, FCFF
- 보고서 선택: `reprt_code=11011` (연간 사업보고서), `[기재정정]` 우선
- 캐시: `valuation_engine/data/xbrl/<회사명>_<연도>.json`

### A-4. KOFIA 채권시가평가기준수익률 (수동 CSV)
- 파일 경로: `VAR/채권시가평가기준수익률[_YYYYMMDD].csv`
- 다운로드: KOFIA 채권정보센터 > 시가평가 > 채권시가평가기준수익률
- 형식:
  ```
  종류,종류명,신용등급,고시기관,3월,6월,9월,1년,1년6월,2년,2년6월,3년,4년,5년,7년,10년,15년,20년,30년,50년
  ```
- 사용 필터: 종류=`회사채 I(공모사채)`, 종류명=`무보증`, 만기=`5년`
- 등급 (KOFIA 정확 표기): AAA, AA+, AA0, AA-, A+, A0, A-, BBB+, BBB0, BBB-
- 단위: % (예: `4.495` → `4.495%` → 소수 `0.04495`)
- 갱신: 사용자 수동 (파일명에 YYYYMMDD 권장)

### A-5. KOFIA CP시가평가수익률 (수동 CSV)
- 파일 경로: `VAR/cp_수익률[_YYYYMMDD].csv`
- 다운로드: KOFIA 채권정보센터 > 시가평가 > CP시가평가수익률
- 형식:
  ```
  신용등급,구분,기관명,7일,15일,1월,3월,6월,1년
  ```
- 사용 필터: 기관명=`5사 평균` (개별 5사 행은 자동 제외)
- 등급 (KOFIA 정확 표기): A1, A2+, A2, A2-, A3+, A3, A3-, B+, B, B-, C, D
- 사용 만기: `1년` (회사채 5년과의 만기 차이로 Term-Credit Spread 계산)
- 갱신: 사용자 수동 (파일명에 YYYYMMDD 권장)

### A-6. 한공회 SRP 테이블 (코드 내장)
- 출처: 2025-06-10 한공회 가이던스
- 3분위: Mid (−0.36%) / Low (+1.37%) / Micro (+4.02%)
- 자동 매칭: `match_srp(market_cap_won)` — 평가기준일 시총 백만원 환산 후 매칭

### A-7. OpenAI ChatGPT 4o-mini (RAG)
- 환경변수: `OPENAI_API_KEY`
- 모델: `gpt-4o-mini` (response_format=json_object, temperature=0)
- 용도:
  - 보통주 발행주식수 + 자기주식수 추출 (`compute_equity.fetch_shares_via_rag`)
  - 회사채/CP 신용등급 추출 (`fetch_credit_rating.fetch_credit_rating_via_rag`)

### A-8. 사업보고서 청크 (jsonl)
- 파일 패턴: `VAR/<KOSPI|KOSDAQ>/<티커>_<회사명>_<연도>_annual_chunks*.jsonl`
- 각 라인: `{"text": ..., "section_path_str": ..., "kind": "table"|"text", ...}`
- 생성: 팀원 사업보고서 임베딩 파이프라인 (별도)

## B. 내부 캐시·결과 파일

### B-1. peer_beta 산출
- 원본 캐시: `peer_beta/data/raw/`
- 정제 패널: `peer_beta/data/processed/weekly_prices_<T>.csv`, `weekly_returns_<T>.csv`
- 최종 결과: `peer_beta/results/peer_beta_<T>.json`
  - 회사별 β_raw, β_adjusted, R², N, alpha, residual_std, outlier_handling

### B-2. XBRL 추출 결과
- 개별: `valuation_engine/data/xbrl/<회사명>_<연도>.json`
- 통합: `valuation_engine/data/xbrl/all_financials_<YYYYMMDD>.json`
- 매 실행 캐시 우선 (skip_existing=True)

### B-3. 시가총액 E
- `valuation_engine/data/equity/peers_equity_<T>.json`
- 회사별 종가, 발행주식, 자기주식, 유통주식, E_market_cap, RAG source/quote/confidence

### B-4. WACC
- `valuation_engine/data/wacc/wacc_result_<T>.json`
- Rf, ERP, SRP·SRP_tier, CRP, 피어 Hamada (β_U, D/E, t), β_U_median, DE_median, β_L_target, t_target, Ke, Kd, credit_rating (회사채/CP + 변환 분해), kd_source (KOFIA 매핑 메타), Kd_after_tax, We/Wd, WACC

### B-5. DCF
- `valuation_engine/data/dcf/dcf_result_<T>.json`
- historical (revenue/ebit/da/capex/nwc), normalization (OPM/DA율/CAPEX율/NWC율, g_3yr_CAGR, tax_rate 헤드라인), fcff_table (Y+1~Y+5 × growth, revenue, ebit, **tax_rate, tax_tier**, tax, da, capex, dnwc, fcff, df, pv), TV/PV(TV)/EV, implied_roic, warnings

### B-6. 최종 평가 결과
- `valuation_engine/results/valuation_<T>.json`
- Streamlit 대시보드가 직접 로드하는 통합 JSON

## E. 단위·시각 규약

- 통화: 원(KRW). 표시 시 억/조 환산.
- 비율: 소수 (예: `0.04495` = 4.495%)
- 일자: ISO 형식 `YYYY-MM-DD`
- 평가기준일 T: `date.today()` 자동
- 회계연도: `FY2023`, `FY2024`, `FY2025` (12월 결산 기준)
