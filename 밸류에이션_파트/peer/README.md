# peer_group_finder

국내 상장기업명 또는 종목코드를 입력하면 해당 기업의 유사기업(Peer Group) 리스트를 자동으로 탐색하여 반환하는 Python 스크립트.

KRX 실시간 데이터와 WICS(WiseFn Industry Classification Standard) 업종 분류를 활용하며, 오프라인 환경이나 API 통신 실패 시에도 내장된 매핑 데이터를 통해 안정적으로 동작합니다.

---

## 주요 기능 및 평가 기준

입력된 기업과 타 기업 간의 유사도(0~1)를 계산하여 상위 5개(Top N) 기업을 반환합니다.

| 구분 | 가중치 / 내용 |
| --- | --- |
| **소섹터 일치** | **0.55** (핵심 기준, WICS 소섹터 단위 일치 여부) |
| **시총 유사도** | **0.30** (시가총액 규모를 6단계 Tier로 나누어 ±2 구간 내 유사성 평가) |
| **중섹터 일치** | **0.15** (밸류체인 인접성 등을 고려한 중섹터 일치 보너스) |
| **입력 방식** | 종목명(예: `삼성전자`), 종목코드(예: `005930`), 대화형 입력 모두 지원 |
| **Fallback** | pykrx 통신 실패 시 스크립트 내장 WICS 매핑 및 시총 근사값 자동 대체 |

> 시가총액 정보가 누락된 경우 섹터 일치도만으로 점수를 정규화하여 계산합니다.

## 알고리즘 단계

1. **데이터 수집:** KRX에서 전 종목 시가총액 및 WICS 소섹터 레벨 분류 수집.
2. **대상 식별:** 입력된 문자열을 파싱하여 타겟 기업의 종목코드 및 섹터/시총 정보 식별 (부분 일치 시 후보군 출력 후 선택).
3. **1차 필터링:** 대상 기업과 동일한 소섹터를 가졌거나, 최소한 중섹터가 일치하는 기업 추출.
4. **2차 필터링:** 시총 구간을 나노캡부터 메가캡까지 6단계로 분류하고, 대상 기업과 ±2 구간 이상 차이 나는 종목 제외.
5. **스코어링:** 남은 후보군을 대상으로 `소섹터(0.55) + 시총(0.30) + 중섹터(0.15)` 가중치를 합산하여 상위 N개 반환.
