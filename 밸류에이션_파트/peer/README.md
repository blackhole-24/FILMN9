# peer_group_finder_v7

국내 상장기업명 또는 종목코드를 입력하면 정교한 알고리즘을 통해 가장 적합한 유사기업(Peer Group) 리스트를 산출하여 반환하는 Python 모듈입니다.

v7 업데이트를 통해 기존에 발생하던 이종 산업 혼입(Cross-industry Contamination) 문제를 해결하고, 삼성전자와 같은 복합·초대형 기업부터 단일 비즈니스 모델을 가진 기업까지 범용적으로 커버할 수 있도록 고도화되었습니다.

---

## 주요 평가 지표 및 알고리즘

| 구분 | 항목 |
|------|------|
| 스코어링 | 소섹터 일치(0.65) + 시총 로그 연속형 유사도(0.35) 기반 합산 점수 산출 |
| 하드컷 필터 | 시가총액 차이가 `MAX_LOG_DIFF`(약 244배) 초과 시 Peer 후보에서 즉시 제외 |
| 비즈니스 태그 | `BIZ_TAG` 도입. 동일 섹터라도 비즈니스 모델(예: 신약개발 vs CMO)이 다르면 섹터 점수 60% 패널티 |
| 교차 섹터 매칭 | `_CROSS_SECTOR_WHITELIST` 적용. 실제 밸류체인 상 비교 가능한 이웃 섹터만 명시적 허용 |
| 엣지 케이스 | `MULTI_SECTOR_MAP`으로 지주사/복합기업 분할 가중치 적용, `MONOPOLY_SET`으로 국내 Peer 부족 기업 예외 처리 |

## 설치

```bash
pip install finance-datareader yfinance pandas

```

별도의 API 키 설정은 필요하지 않으며, 실시간 시가총액 데이터를 위해 외부 라이브러리에 순차적으로 접근합니다.

## 사용법

### CLI (터미널)

```bash
# 대화형 모드로 실행
python peer_group_finder.py

# 종목코드로 직접 조회
python peer_group_finder.py 005930

# 종목명으로 직접 조회 (대소문자, 공백 무관)
python peer_group_finder.py 삼성전자
python peer_group_finder.py sk하이닉스

```

## 데이터 소스 기준

* **시가총액 조회 순위**
1. `FinanceDataReader` (`fdr.StockListing('KRX')`)
2. `yfinance` (`fast_info.market_cap`)
3. 내장 오프라인 근사값 테이블 (`MKTCAP_APPROX`) 자동 폴백


* **섹터 데이터**
* 자체 내장 `WICS_SECTOR_MAP` 활용하여 외부 의존성 및 호출 지연 최소화
