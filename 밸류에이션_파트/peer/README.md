# peer_group_finder_v5

국내 상장기업명 또는 종목코드를 입력하면 알고리즘을 통해 가장 적합한 유사기업(Peer Group) 리스트를 반환하는 Python 스크립트입니다. 검색어 정규화를 지원하여 대소문자, 공백, 특수문자에 구애받지 않고 유연하게 기업을 검색할 수 있습니다.

---

## 주요 구성 요소

| 구분 | 내용 |
|------|------|
| **섹터 데이터** | 주요 상장기업이 커버된 내장 `WICS_SECTOR_MAP` 사용 |
| **시총 소스 1순위** | `FinanceDataReader` (KRX 전종목) |
| **시총 소스 2순위** | `yfinance` (개별 종목) |
| **시총 소스 3순위** | 내장 오프라인 근사값 테이블 (`MKTCAP_APPROX`) |

> 모든 시가총액 데이터는 **원(KRW)** 단위로 처리 및 계산됩니다.

---

## 설치

실행에 필요한 외부 라이브러리를 설치합니다.

```bash
pip install finance-datareader yfinance pandas

```

## 사용법

### CLI (터미널)

명령어 인수로 검색어를 직접 전달하거나, 인수 없이 실행하여 대화형 모드를 사용할 수 있습니다.

```bash
# 대화형 모드로 실행
python peer_group_finder_v5.py

# 종목코드로 조회
python peer_group_finder_v5.py 005930

# 종목명으로 조회
python peer_group_finder_v5.py 삼성전자

# 대소문자 및 띄어쓰기 무관 조회
python peer_group_finder_v5.py sk하이닉스

```

## 유사도 산출 알고리즘

입력 기업과 대상 기업 간의 유사도 스코어(0~1)를 산출하여 가장 높은 순서대로 최대 5개(Top N)를 정렬하여 반환합니다.

* **소섹터 일치 (+0.60):** 두 기업의 소섹터가 완전 동일한 경우.
* **시총 구간 유사도 (+0.35):** 나노캡부터 초대형캡까지 6단계의 Tier로 나누어, Tier 차이가 적을수록 높은 점수 부여.
* **중섹터 보너스 (+0.05):** 동일한 중섹터이거나, 인접한 밸류체인(허용된 소섹터 쌍) 내에 있는 경우.
* **완전 제외:** 중섹터가 완전히 다른 기업은 스코어를 0.0으로 처리하여 결과에서 제외합니다.
