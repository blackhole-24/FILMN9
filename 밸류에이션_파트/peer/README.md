# peer_group_finder_fullkrx_A

국내 상장 전종목(~2,766개)을 대상으로 기업명 또는 종목코드를 입력하면 정교한 알고리즘을 통해 가장 적합한 유사기업(Peer Group) 리스트를 산출하여 반환하는 Python 모듈입니다.

v7의 WICS 수동 매핑 기반 알고리즘을 완전히 보존하면서, KRX 전종목 업종 데이터(`krx_desc.csv`)를 WICS 섹터 체계로 자동 변환하는 방식으로 커버리지를 기존 ~250개에서 ~2,766개로 확장하였습니다.
시총 미공개 기업의 Peer 오염 문제를 해결하기 위해 후보 분리 수집 및 조건부 보충 로직을 도입하였으며, Peer 수를 5개로 고정하지 않고 납득 가능한 수만큼만 반환하도록 개선하였습니다.

---

## 주요 평가 지표 및 알고리즘

| 구분 | 항목 |
|------|------|
| 스코어링 | 소섹터 일치(0.65) + 시총 로그 연속형 유사도(0.35) 기반 합산 점수 산출 |
| 하드컷 필터 | 시가총액 차이가 `MAX_LOG_DIFF`(약 244배) 초과 시 Peer 후보에서 즉시 제외 |
| 비즈니스 태그 | `BIZ_TAG` 도입. 동일 섹터라도 비즈니스 모델(예: 신약개발 vs CMO)이 다르면 섹터 점수 60% 패널티 |
| 교차 섹터 매칭 | `_CROSS_SECTOR_WHITELIST` 적용. 실제 밸류체인 상 비교 가능한 이웃 섹터만 명시적 허용 |
| 엣지 케이스 | `MULTI_SECTOR_MAP`으로 지주사/복합기업 분할 가중치 적용, `MONOPOLY_SET`으로 국내 Peer 부족 기업 예외 처리 |
| 시총 미공개 처리 | 시총 있는 후보 우선 확보 후 부족분만 조건부 보충 (섹터 완전 일치 & 원점수 ≥ 0.35 & score ×0.70 패널티) |
| 섹터 매핑 우선순위 | WICS 수동 매핑 등록 종목 우선 적용 → KRX 161개 업종 자동 변환으로 fallback |

## 사용법

### CLI (터미널)

```bash
# 대화형 모드로 실행
python peer_group_finder_fullkrx_A.py

# 종목코드로 직접 조회
python peer_group_finder_fullkrx_A.py 005930

# 종목명으로 직접 조회 (대소문자, 공백 무관)
python peer_group_finder_fullkrx_A.py 삼성전자
python peer_group_finder_fullkrx_A.py sk하이닉스

# 전종목 일괄 처리 후 CSV 저장
python peer_group_finder_fullkrx_A.py --batch output_A.csv
```

### 모듈로 사용

```python
from peer_group_finder_fullkrx_A import build_universe, find_peer_group

df = build_universe("krx_desc.csv", "data_2621_20260519.csv")
peers = find_peer_group("삼성전자", df)
```

## 데이터 소스 기준

**시가총액 조회 우선순위**

1. `data_2621_*.csv` — KRX 공시 자기주식 제외 시가총액 (가장 안정적)
2. `FinanceDataReader` — `fdr.StockListing('KRX')` 실시간 조회
3. `yfinance` — `fast_info.market_cap` 개별 종목 조회

**섹터 매핑 우선순위**

1. 내장 `WICS_SECTOR_MAP` — 주요 상장기업 약 250개 수동 정의 (v7 완전 보존)
2. `KRX_TO_WICS` 자동 변환 — KRX 161개 업종명 → WICS 소섹터/중섹터 룰 기반 매핑

---

## 출력 항목 설명

| 항목 | 설명 |
|------|------|
| `[WICS]` | WICS 수동 매핑 종목 (신뢰도 높음) |
| `[KRX]` | KRX 업종 자동 변환 종목 |
| `※시총미공개` | 시총 데이터 없는 보충 후보 (score ×0.70 패널티 적용) |
| `※ 충분한 Peer 미확보 (N/5)` | 납득 가능한 Peer가 5개 미만인 경우 실제 수만 반환 |
